# L. 평가 프레임워크 — 축 B 성과 입증의 기반

> 조사일: 2026-08-15
> 브리프 5.5: 평가셋이 먼저다. 축 B의 "베이스 대비 개선폭" 주장 전체가 이 영역에 의존한다.

---

## 결론 요약

| 평가 대상 | 선정 | 근거 |
|---|---|---|
| **검색(Embed·Rerank)** | **자체 하네스 + pytrec_eval/ranx** | Recall@k·MRR·nDCG는 결정론적 지표 — LLM 저지 불필요, 프레임워크 없이 표준 IR 라이브러리로 재현 가능하게 구현. **축 B 검색 트랙의 공식 측정 도구** |
| **생성(Writer) — LLM 저지** | **DeepEval** (17.6k★, Apache 2.0, 활발) | pytest 호환 — 회귀 테스트로 반복 학습 사이클(v0.1→v0.2)에 물림. G-Eval 방식 커스텀 지표 정의 지원. **로컬 모델을 저지로 사용 가능**(온프레미스 필수 조건) |
| **생성 — 결정론적 커스텀 지표** | **자체 구현 (프레임워크 밖)** | ①평가지표 반영률: 공고 스키마의 배점 항목 대비 본문 커버리지 — 배점 대조 검증기(6장)와 동일 로직 재사용 ②**수치 환각률: 생성문 수치 ↔ 인출 근거 대조 — 문자열·DB 매칭이지 LLM 판단이 아님.** 이 두 지표는 본 프로젝트 고유 로직(5.1) |
| **회귀·프롬프트 비교** | promptfoo (24.2k★, MIT) — 대안/보조 | 설정 파일 기반 A/B — 프롬프트·모델 버전 비교 리포트에 유용. 채택은 선택적 |

**핵심 인식**: 축 B의 4개 모델 중 3개(Embed·Rerank·Extract)는 **결정론적 지표**(Recall/nDCG, 필드 정확도)로 평가된다 — RAG 평가 프레임워크의 주특기(LLM 저지)가 필요한 것은 Writer뿐이다. 따라서 "프레임워크 선정"보다 **평가셋 구축(문항·정답·검수 절차)이 실작업의 90%**이며, 이는 Phase 1 `docs/eval-plan.md`에서 상세 설계한다.

## 판정 상세

- **Ragas 탈락**: RAG 평가의 개념적 표준(faithfulness, context precision 등)을 세운 프로젝트이나 vibrantlabsai 이관 후 2026-02 이후 커밋 정체. 지표 정의는 차용하되 라이브러리 의존은 회피.
- **TruLens 탈락**: 관측(observability) 지향 — 우리 요구(오프라인 벤치마크·개선폭 측정)와 용도 불일치. 규모도 열세.
- **AutoRAG 관찰**: 한국 기업(Marker-Inc) 프로젝트로 한국어 문서화·사례 강점. RAG 구성요소 자동 최적화(AutoML식)가 주기능 — 청크 크기·검색 파라미터 탐색에 Phase 3에서 참고 가치. 단 자체 파이프라인 구조를 강제하므로 전면 채택은 B 영역 결정(얇은 조립)과 충돌. 라이선스 표기 확인 필요.
- **DeepEval 채택 조건**: LLM 저지를 **로컬 vLLM 엔드포인트**(Qwen3.5급)로 설정 — 외부 API 전송 금지(온프레미스 원칙). 저지 모델·프롬프트·버전을 평가 보고서에 고정 기록(재현 절차 요건).

## 평가 체계 스케치 (Phase 1 eval-plan.md의 입력)

| 트랙 | 지표 | 도구 | 성격 |
|---|---|---|---|
| Embed/Rerank | Recall@k, MRR, nDCG | pytrec_eval/ranx + 자체 평가셋 | 결정론적 |
| Extract | 필드별 정확도(F1), 처리량 배수 | 자체 스크립트(정답 대조) | 결정론적 |
| Writer | 평가지표 반영률 | 배점 검증기 로직 재사용 | 결정론적 |
| Writer | **수치 환각률(→0 필수)** | 수치 인출 대조기 | 결정론적 |
| Writer | 문체 적합성·논리 완결성 | DeepEval(로컬 저지) + **사람 평가** | 판단적 |

사람 평가 프로토콜(담당자 블라인드 비교, 문항 수, 합의 규칙)은 eval-plan에서 설계 — 사람 평가 없이 LLM 저지만으로 "문체 개선"을 주장하지 않는다(축 B 방어력).

## 위험
1. LLM 저지의 편향(자기 문체 선호 등) — 저지 모델을 Writer 베이스와 다른 계열로 선정해 상관 편향 완화.
2. 평가셋 오염 — Writer 학습 데이터(과거 계획서)와 평가셋 문항의 출처 분리를 데이터 정제 단계에서 강제(50-model-track 상세).
