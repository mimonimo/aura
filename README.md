# ZZAIMY (짜이미)

영남이공대학교 행정문서 처리 플랫폼이다. 국고사업 공고·계획서·결과보고서 같은 교내 문서를 읽어
근거를 찾고, 검토 의견과 사업계획서 초안 작성을 돕는다. 모델은 교내 장비에서 돌린다. 작성 중인 작업본은 학교
Google 계정의 Docs에 두고, 외부 검색을 켠 질문만 질문 글이 밖으로 나간다. 산출물은 초안이며, 고쳐 쓰고 판단하는
일은 담당자가 맡는다.

2026년 2학기 캡스톤 프로젝트로, 9월부터 11월까지 구축하고 12월에 교내 발표회에서 결과를 보인다.
문서 반입부터 검색·검토·초안 작성·한글 산출까지 이어지는 웹 플랫폼을 만드는 일(축 A)과, 오픈웨이트 모델 4종을
교내 문서 작업에 맞게 학습하는 일(축 B)을 함께 진행한다.

## 기능

문서를 반입하면 PDF·HWP·HWPX·오피스 문서에서 본문·표·그림을 뽑고, 스캔 문서는 판독한 뒤 서류 갈래와 사업을
분류한다. 뽑은 글은 조각으로 나눠 색인하고, 사업 → 연차 → 문서 → 절의 관계를 지식 그래프로 묶는다. 사업 사이의
연결은 근거가 확인된 경우에만 만든다.

질문에는 어휘 검색과 의미 검색을 합친 결과로 답하고(규정 문서는 리랭커로 한 번 더 재정렬한다), 답마다 원문 출처를 붙인다. 열람 권한은 검색
단계에서 거르므로 볼 수 없는 문서는 근거로도 쓰이지 않는다.

문서 작성은 Google Docs 작업본에서 절 단위로 한다. 쓴 글의 수치는 근거와 대조해 근거에 없는 값을 가리고 담당자에게
확인을 청한다. 마친 작업본은 원본 HWPX 서식에 채워 한글 파일로 내보낼 수 있다. 학습 데이터는 실문서에서 만든 후보를
사람이 검수하고 승인한 것만 쓴다.

## 동작 방식

```
문서 반입 → 추출·분류 → 조각·색인(어휘 + pgvector) ─┐
                                                    ├→ 검색·재정렬 → 답변·검토·절 작성 → 수치 대조·품질 관문
지식 그래프(사업·연차·문서·절) ──────────────────────┘
```

문서 작업에서는 Writer 모델이 요청을 읽고 다음에 할 일을 고른다. 자료 찾기, 절 읽기, 양식 고르기, 절 쓰기, 검토,
내보내기, 되묻기 가운데 하나를 고르면 코드가 실행한다. 열람 범위, 수치 대조, 양식 모양, 반복 횟수 제한은 코드가
지키고, 모델 응답이 깨지면 규칙 기반 경로로 돌아간다. 사실 정보는 검색으로 넘기고, 모델에는 맥락을 파악해 근거를
골라 쓰는 능력만 학습시킨다.

## 모델

| 모델 | 베이스 | 역할 | 상태 (2026-10-11) |
|---|---|---|---|
| ZZAIMY-Embed | KURE-v1 | 의미 검색 | v2 운영 |
| ZZAIMY-Rerank | bge-reranker-v2-m3 | 검색 후보 재정렬 | v1 운영 |
| ZZAIMY-Writer | Qwen3.8-27B | 문서 이해·검토·초안 작성·그림 판독 | 베이스 모델 운영, 학습 데이터 구축 중 |
| ZZAIMY-Extract | Qwen3.8-27B (Writer 와 같은 모델, 형식 강제) | 실적 정보 구조화 | 학습·평가 전 |

모델은 위 4종만 쓰고, 새 후보는 결정 기록과 비교 측정 뒤에만 들인다. 계획과 근거는
[모델 개발 계획](docs/model-plan.md), 학습본의 측정 결과는 [모델 카드](docs/model-cards/)에 있다.

## 기술 구성

| 구분 | 내용 |
|---|---|
| 웹 플랫폼 | FastAPI, PostgreSQL(pgvector), Google Docs·Drive 연동 |
| 모델 서빙 | vLLM, Writer 27B NVFP4 (젯슨 토르 2대) |
| 학습 | LLaMA-Factory, sentence-transformers (DGX) |
| 문서 추출 | 디지털 PDF 글자층 직독(pypdf), 스캔 PDF는 MinerU, 한글·docx·xlsx는 kordoc과 자체 변환기, 오피스는 python-docx·openpyxl·python-pptx, 옛 형식 변환은 LibreOffice |
| 지식 그래프 | PostgreSQL 테이블, rdflib·pySHACL(온톨로지 내보내기·검사), Cytoscape.js(탐색 화면) |

## 저장소 구조

```
src/zzaimy/   플랫폼 구현 — app(화면·API·에이전트), ingest, index, retrieve, graph, generate, extract, verify, eval, dataset
scripts/      반입·색인·측정·학습·서빙·배포 도구 (번호 순)
configs/      학습·서빙 설정
tests/        회귀 테스트
docs/         설계·결정 기록(ADR)·측정 보고서·모델 카드·논문 자료
research/     착수 단계 기술 조사 기록(참고용)
```

실제 문서와 처리 결과, 비밀값은 저장소에 넣지 않는다.
