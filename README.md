# ZZAIMY (짜이미)

영남이공대학교 행정문서 처리 플랫폼. 교내 로컬 모델로 문서를 분석하고,
원문 근거를 찾아 검토 의견과 사업계획서 초안 작성을 지원한다.

## 주요 기능

- PDF·HWP·HWPX 문서의 본문·표·이미지 추출
- 사업별 문서 분류와 계획·실적·평가 자료의 관계 분석
- 문서 검색과 출처를 확인할 수 있는 질의응답
- 근거 기반 문서 검토·초안 작성
- Google Docs 공동 작업과 원본 서식 기반 HWPX 산출

각 사업은 독립적으로 분석하며, 근거가 확인된 관계만 연결한다.
수치는 원문에서 인출하고 출처를 남긴다. 산출물의 최종 판단은 담당자가 한다.

## 모델 개발

| 모델 | 역할 | 상태 |
|---|---|---|
| ZZAIMY-Embed | 근거 검색 | v2 적용 |
| ZZAIMY-Rerank | 검색 후보 재정렬 | v1 적용 |
| ZZAIMY-Writer | 문서 이해·검토·작성 | 베이스 모델 운영, 학습 데이터 보강 중 |
| ZZAIMY-Extract | 실적 정보 구조화 | 전용 학습·평가 준비 전 |

여러 사업의 데이터를 함께 학습하되, 질문·이전 대화·근거·답변의 사업 맥락을
유지한다. 지식은 검색으로 제공하고, 모델은 맥락 파악과 근거 활용 능력을 학습한다.
