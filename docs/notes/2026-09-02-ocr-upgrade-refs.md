| Upstage OCR 라벨링 인터뷰 | 라벨링 기준 설계·품질 관리·특화 모델 구축 실무 | **프로세스 도입** (도구 아님) | 아래 3가지가 우리 실데이터 파일럿 계획에 그대로 이식된다 |

Upstage 인터뷰에서 이식할 3가지 (실데이터 파일럿 설계에 반영):
1. 일반+특화 병행 — 범용 추출(현 파이프라인)을 유지하고, 자주 오는 서식(공고문·
   신청서)만 특화 처리를 얹는다. 전면 교체 금지
2. 하드케이스 마이닝 루프 — 초기 모델로 대량 처리 → 어려운 케이스만 골라 라벨링 →
   재학습. 우리 플랫폼의 판정(승인·반려)·담당자 의견이 곧 이 라벨링 채널이다.
   담당자가 고쳐준 부분 = 학습 데이터. 별도 라벨링 도구 없이 운영 속에서 수집
3. 실수 방지형 입력 설계 — 라벨(판정·의견)을 받는 UI가 곧 데이터 품질을 결정.
   판정 3버튼·의견 텍스트 같은 제약된 입력을 유지하고 자유 형식을 늘리지 않는다
