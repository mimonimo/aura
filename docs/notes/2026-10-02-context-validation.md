# 컨텍스트 처리와 실문서 평가 후보

문서 작성 경로의 입력 예산 검사와 선택 근거의 출처 표시를 보강했다.
길이 초과 재현 3건을 수정했고, fake client로 초과 요청의 모델 호출 차단과
출처·담당자 지시 보존을 확인했다. 전체 검사 1,022개 통과, 6개 건너뜀.
문자 기반 토큰 추정이며 의미 요약·긴 대화 메모리의 완성을 의미하지 않는다.

## 실문서 평가 후보

자동 분류상 9개 사업의 문서 30개에서 사업·연차·문서·절과 원문 근거를 묶었다.
`scripts/build_graph_retrieval_probes.py`는 읽기 전용 DB 스냅샷으로 후보를 만들고
매번 새 내부 평가 폴더에 저장한다. 실패 문서는 제외하고 원문·그래프 해시를 기록한다.
본문은 Git에 저장하지 않는다. 답변·검수 승인은 비워 두고 학습 대상에서도 제외한다.

제목 기반 자기 검색 표본이므로 실제 사용자 질문 평가나 독립 정답 세트를 대체하지 않는다.
그래프 변경으로 첫 묶음의 평가를 중단한 뒤, 그래프 전체 스냅샷을 함께 저장하도록
보강했다. 고정된 두 번째 묶음은 생성됐지만 학교망 접속 장애로 검색 점수 측정은 미실시다.

## 남은 검증

최근 대화 6개를 읽는 현재 응답 경로는 검색 이후에 대화를 붙인다. 앞 대화의 사업·연차와
정정을 검색 질의에 전달하는 연결, 복수 사업 비교, 압축 뒤 맥락 복원은 별도 구현·평가가
필요하다. 운영 배포와 실사용 모델 응답 검증도 완료하지 않았다.
