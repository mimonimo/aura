## 정합 분석 (구현 기준, 2026-09-08)

일치하는 것 — 이미 그 방향으로 구축돼 있다.

- "규정 같은 휘발 데이터는 RAG로"(8) = 브리프 절대 규칙 8(지식은 검색으로
  공급)과 동일. 데이터 공방도 기준 문서를 학습 쌍에서 제외하도록 구현됨.
- 온톨로지 고려 데이터·학습(6) = ADR-0009 경량 온톨로지 v1 + 지식 그래프
  1단계(/graph 가동 중). SFT→온톨로지→학습→활용→Graph 순환은 데이터
  공방(변환·대장) + 그래프 2단계(개체 추출)로 이어진다.
- 업무 노하우 학습(3) = 데이터 공방의 세 소스(검토 의견·초안·대화)가 정확히
  "업무 결과물+메모"다. 매뉴얼류는 기준 저장소에 이미 수용.
- 하이브리드(7) = 사용자 확정(2026-09-08) 최종 형태와 동일.
