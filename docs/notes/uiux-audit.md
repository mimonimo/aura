# UI/UX 전수 조사

작성 2026-09-08, 후속 반영 2026-09-16까지. 로컬 앱 전 화면을 헤드리스 크롬으로 1600px·1100px 두 폭 캡처해 점검했다.

점검 축: 계열 디자인 일관성, 화면 문구 규칙(짧은 명사형·이모지 배제), 정보 위계, 빈 상태 안내, 반응형, 접근 동선, 오류·대기 상태 표시.

## 전반

사이드바 248px 고정 + 상단바 + 라운드 카드 구조와 색(네이비·포인트블루·연회색 배경)이 전 화면에 일관된다. 화면 문구는 대체로
짧은 명사형이고 라인 아이콘만 쓴다. 빈 상태 안내와 개인정보 안내가 화면마다 있다. 큰 구조 문제는 없었고 아래는 다듬을 지점이다.

## 화면별 발견 (2026-09-08)

- /chat: 입력창이 두 개로 보였으나 과대 세로 캡처를 잘못 읽은 것이었다. 실제 입력창은 하단 고정 하나다.
- /dev: 추출 품질 카드의 깨진 글자는 개발 중 URL 인코딩 없이 넣은 로컬 시험 데이터였다. 정상 입력은 UTF-8 로 저장된다(테스트로 확인).
  카드가 많아 페이지가 길다.
- /settings: 카드는 넓은데 폼이 왼쪽 500px 에 몰려 오른쪽 여백이 크다.
- /project: 지침·메모 카드의 빈 상태 아이콘이 살짝 잘린다. 2단 그리드는 1080px 이하에서 1단으로 바뀌어 정상이다.
- /dev/db: 1100px 에서 파일명 열이 잘렸다. `.table-scroll` CSS 규칙이 없어 가로 스크롤도 안 됐고, base.html 에 규칙을 넣어 고쳤다(9/14).
- /dev/egress, /criteria, /ocr, /: 큰 문제 없음.

반응형: 좁은 폭에서도 사이드바가 248px 로 고정돼 1100px 안팎에서 표와 2단 배치가 눌린다. 1080px 이하에서 사이드바를 접는다.

조사 한계: 로컬 표본이 미처리 상태라 문서 상세의 초안·AI 읽기 뷰어·인식 영역 팝업은 운영 VM 에서 따로 봐야 한다. 인증 없는
모드라 /login 이 홈으로 넘어가고, 모델이 없어 검색 의존 기능은 미검증이다.

## 후속 반영

### 처리 현황·문서함

- 처리 현황 타일은 필터가 아니라 읽기용이다. 「처리 현황」 라벨과 접수 → 처리 중 → 검토 완료 → 판정 대기 흐름으로 보인다.
- 계정 칩은 흰 바탕·연한 테두리.
- 남은 일: 문서 추출(OCR) 머리를 다른 화면의 표준 머리로, 산출물 반출 항목별 내용·용량 설명, /dev/db 엑셀형 그리드.

### 개발자 영역 중복 통합 (9/15)

같은 원천을 두 번 그리던 것만 합쳤다.

- 규모 타일: /dev 와 /dev/db 가 같은 SQL 을 다른 이름으로 보이던 것을 공용 조각 `_stat_tiles.html` 과 원천 `_data_overview()` 하나로.
- 구축 진행률: 근거 없는 영역별 수기 퍼센트를 지우고 기능별 상태만 남겼다.
- 최근 개선 내용과 전체 변경 목록은 「변경 이력」 하나로.
- 학습 도구 설명은 /dev/train 이 원본이고 나머지는 한 줄.

일부러 합치지 않은 것: 진행 현황(dev-now.md, 서술)과 구축 현황(progress.json, 상태표), 모델 4종 표와 학습 도구 카드,
데이터 만들기 단계와 학습 절차.

### 모델 학습 화면·문구 (9/15)

- /dev/train: 데이터 공방·Label Studio·TensorBoard 를 같은 구조·같은 높이 카드로(LLaMA Board 카드는 10-18 걷어냄). 각 카드의 설정 창에 주소·상태·키·계정.
  별도 계정 페이지(/dev/accounts)는 지우고 /dev/train 으로 301.
- 설명 단락은 한두 문장·명사구로 줄였다. 교내 장비 처리·개인정보 안내는 화면마다 적지 않고 사이드바 하단 한 줄(.side-note)로.
- /dev 진행 현황은 최신 날짜만, 전체는 /dev/history 「작업 기록」.

### 버튼 체계·허브 (9/15)

- 주 버튼은 잉크색(#1F2937) 하나, 보조 버튼은 흰 바탕 + 슬레이트 테두리. 파랑 채움·글로우는 뺐다. 카드 머리 보조 링크용 `.h-link`.
- /dev: 프로젝트 현황 카드 하나(개요 + 규모 칩 + [구축 현황 | 진행 현황] 탭), 모델 개발 흐름(데이터 열람 → 데이터 공방 → 모델 학습
  → 품질·성능), 운영 도구, 문서·기록.
- 산출물 반출은 파일별 직접 내려받기, 여러 항목일 때만 zip.
- Label Studio 비밀번호 재설정은 stdout 마지막 줄로만 판정한다(stderr 경고를 실패로 읽던 오류 수정).
- 문서 열람(/dev/docs·/dev/doc): 종류별 카드와 행, 본문 78ch·15px·행간 1.75, 오른쪽 고정 목차. /dev/history 는 날짜별 작업 기록과
  커밋 묶음.
- 데이터 열람: 문서 중심 탐색기(왼쪽 목록, 오른쪽 개요·마스킹 기록·추출 조각·검색 단위·연관). 표 조각은 칸 글자를 이어 보인다.
- 채팅 작업 사이드바의 깜빡임은 저장된 상태를 첫 그리기 전에 적용해 없앴다.

### 나머지 화면 점검 (9/16)

- /doc: 계획서 초안을 마크다운 원문 대신 렌더해 보인다. 다시 쓰기는 초안 카드 안 접이식으로.
- 카드 머리 버튼이 찌그러지던 것은 `.card h2` flex-wrap 으로.
- /chat: 작업 패널이 열려도 말풍선 여백이 음수가 되지 않게 했다. 실패 답변에서 예외 이름을 빼고 상태 문장으로 보인다.
- /dev/egress 숫자 타일은 한 줄 칩으로. /settings 하단의 중복 개인정보 안내를 지웠다.
- /dev/train 에 모델 서버(vLLM) 카드: 서버가 응답하면 모델 목록에서 고르고, 아니면 직접 입력한다.
- 사이드바 하단에 모델 서버 연결 상태(60초 캐시).
- LLM 연결 종류는 교내 GPU 서버와 외부 기관 GPU 서버 두 가지다. 외부 기관 서버를 문서 작업 기본으로 쓸 때만 승인 확인을 거친다.
- NAS 원천 추가 창은 연결·파일·반입 대상·자동 반입 네 묶음, 폴더 찾아보기, 파일 종류·날짜·크기 필터, 반입 미리보기.
