# 자료 보관·접근·삭제 범위 — 실물 문서 반입 전 확정안

작성 2026-09-24. 아스트라의 반입 전 검토(2026-09-22) 3항에 대한 답이다. 학교 개인정보 부서 확인 전이므로 "안"이다.

| 자료 | 어디에 | 누가 보나 | 언제까지 | 지우면 무엇이 지워지나 |
|---|---|---|---|---|
| 원본 파일 | `documents/반입/<연도>/<유형>/<접수번호> <제목>/원본.<확장자>` | 열람 등급대로(공개·부서·담당자), 관리자 | 문서를 지울 때까지 | 문서 폴더째(원본·추출 그림·판독 부산물) + DB 문서·조각·장부 |
| 마스킹 본문·조각 | DB `documents.masked_text`, `doc_chunks`, `regulation_chunks` | 검색·화면은 등급대로 | 문서와 같이 | 문서 삭제와 함께 |
| 마스킹 기록 | DB(유형·건수·마스킹본 문맥만, 원문 값 없음) | 관리자(/dev/pii) | 문서와 같이 | 문서 삭제와 함께 |
| 판독 쪽 그림·복원 PDF·글자 좌표 | `cache/`(재생성 가능) | 문서 경로와 같은 등급 | 언제든 지워도 됨 | 다음 열람 때 다시 만든다 |
| 대화 첨부 | `documents/첨부/<연도>/대화-<번호>/` | 그 대화의 주인 | 대화를 지울 때까지 | 대화 삭제 때 파일도(장부에서 찾아) |
| 생성 파일(초안·OCR·복원·추출결과 사본) | `documents/생성/<연도>/<접수번호>/` | 문서와 같은 등급 | 문서와 같이 | 문서 삭제 때 폴더의 사본도 |
| 색인·임베딩 | `knowledge/index/` | 검색 경로만(파일 직접 공개 없음) | 재색인 때 갱신 | 재색인이 곧 삭제·재생성 |
| 지식 내보내기 묶음 | `knowledge/exports/<시각>/` | 관리자가 만들고 외부로 보낸다 | 보낸 뒤 지운다 | 수동 |
| DB·조각·색인 백업 | `backup/` | 관리자 | 30일 뒤 정리(제안) | 수동 |
| 감사 기록(권한 밖 시도·독스 쓰기) | `access_audit.jsonl`, `gdocs_audit.jsonl` | 관리자 | 1년(제안) | 수동 |

열람 등급은 검색만이 아니라 문서 경로 전부(화면·원본·쪽 그림·복원·내보내기·삭제)에 강제된다(2026-09-24, `check_auth` 관문,
`tests/test_doc_visibility.py`). "잔여 0"은 정규식 탐지 범위의 결과이지 개인정보 부재의 보증이 아니다. 문서 삭제 시 생성 사본과
대화 첨부까지 함께 지우는 것은 아직 장부 기준 수동이다(다음 일).

학교와 확정할 것: 보관 기간(원본·백업·감사), 삭제 요청 처리 창구, 담당자 한정 등급의 부여 기준.
