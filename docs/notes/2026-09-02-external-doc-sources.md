# 맥락 고도화용 공개 문서 소스 (2026-09-02, 서브에이전트 조사)

실데이터 도착 전 파이프라인 고도화(추출 검증·공고 스키마·검토 기준·초안 양식)용.
다운로드본은 data/external/ (커밋 금지 — .gitignore 적용 영역).

## 즉시 다운로드 확인된 대표 문서
- 2026 서울RISE 공고문 (연세대 산학협력단 미러, PDF) — 공고 스키마·grant 기준
- KCUE 대학 전임교원 공채 공고문+심사기준표 (PDF 2.1MB) — 배점 구조, recruit 기준
- 전주대 교수채용 공고문 (PDF) — recruit 기준
- 연세대 2027 입학전형시행계획 / 서울대 2027 수시모집 안내 (PDF) — admission 기준
- 2027 대학입학전형기본사항 (대교협, PDF) — admission 표준 일정
- 대전TP RISE 사업 공고 첨부 — grant

## 포털 (지속 수집처)
- 한국연구재단 UniAll(uniall.nrf.re.kr) — 대학재정지원사업 통합
- IRIS(iris.go.kr) — 범부처 사업공고
- 하이브레인넷·나라일터 — 교원·계약직 채용 (참고: 나라장터 아님)
- 서울시 정보소통광장·행안부 공공서식 — 결재문서·서식 원형
- AI-Hub 공공행정문서 OCR — 라이선스·PII 검토 후 벤치마크 용도만
