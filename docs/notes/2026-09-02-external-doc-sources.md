## 실전 검증 결과 (2026-09-02 오후, 서울RISE 공고 PDF)

공고 스키마 추출을 외부 실물 공고로 처음 검증했다.

- 발견 결함: ① 섹션이 1개로 뭉개짐 ② 사업비 수치를 배점(1000점)으로 오인
- 조치: 스키마 프롬프트 보강 — 목차 항목별 분리 강제, 배점은 배점표·심사기준의
  숫자만(예산·인원 금지), 배점표 없으면 빈 배열
- 재검증: 섹션 다항목 분리 + 배점 25개가 실제 심사표 수치(150·200·300점)로 정확
  추출됨. 외부 공고 → 스키마 → (초안 생성 입력) 경로가 실물에서 동작 확인

교훈: 합성 데이터로는 안 보이던 결함이 실물 1건에서 바로 드러남 — 외부 공개
문서 검증의 가치가 입증됨. 남은 공개 문서(채용 심사기준표 등)도 같은 방식으로 순회 예정.
