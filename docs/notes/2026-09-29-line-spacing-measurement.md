## 한글 쪽 사실(구조 XML 의 LineSeg·셀 높이)

- 줄 pitch = height + space-below = 글자 크기 × 비율. 12pt·160% = 1200+720, 11pt·120% = 1100+220, 9pt·105% = 900+44.
- 셀 높이 = 글자 높이 합 + 셀 마지막 줄을 뺀 여분 + 안쪽 여백. 12pt·160% 한 줄 칸 1200HU, 10pt·130% 세 줄 칸 3883HU(30+6+2.82pt).
- 셀 안쪽 여백은 표마다 다르다(위원회 표 위·아래 0, 좌우 538HU; 보통 141).
- 글자에 장평 95%·90% 가 흔하다(사업계획서: 95% 12,616자, 90% 1,330자). 독스는 글자 폭 조절이 없다.
