# 원본·파생 자료 동기화 검수

2026-10-02 로컬 코드 기준. 운영 반영과 전송 무결성은 별도 확인 대상이다.

## 관리 기준

대량 반입과 사용자 첨부는 같은 문서 ID를 중심으로 연결한다. DGX는 원본을 보관하고,
VM은 DB·검색 색인·온톨로지·지식그래프를 관리한다. 첨부 문서는 재학습 없이 작업 근거로
사용한다. 검색 활용이 학습 승인이나 다른 사용자에 대한 공개를 뜻하지 않는다.

원본은 사용자·프로젝트 경계 안에서 사업, 연차, 문서 종류, 문서 ID와 버전을 구분한다.
사업 미확정 자료는 미분류로 남긴다. 원래 파일명·반입 경로를 보존하고 동명 파일은
덮어쓰지 않는다. 기존 DGX 수신 폴더를 이동하기 전에 장부와 참조 경로를 대조해야 한다.
폴더는 탐색 수단이며 권한 판단은 DB 정책을 따른다.

## 재현된 결함

`tests/test_sync_review.py --runxfail`로 재현한다. 실서버 접속·문서 반입 없이 임시 DB와
가짜 외부 호출을 사용한다. 알려진 결함의 strict xfail은 완료가 아니라 미해결 표시다.

| 항목 | 재현 결과 | 수정 담당에 요청 |
|---|---|---|
| 후속 잠금 | 170이 잠금을 가진 채 같은 잠금이 필요한 164를 기다림 | 잠금 소유자를 한 곳으로 통일 |
| 색인 실패 | 실패 후 다음 실행 표식 없음 | 재시도 대상 유지 |
| 그래프 실패 | 명령 실패 후 다음 실행 표식 없음 | 재시도 대상 유지·실패 상태 반환 |
| 시험 실행 | `--dry`도 후속 갱신 호출 | 모든 쓰기 경로 제외 |
| 이동 판정 | 후보 경로가 여러 개여도 첫 경로에 문서 ID 연결 | 양쪽 모두 유일한 경우만 판정; 원본 해시 대조 |
| DB 연결 | 목록 등록 후 반입된 문서 ID가 장부에 반영되지 않음 | 불변 파일도 문서 연결 갱신 |
| 개인 첨부 | 다른 사용자의 원본 경로가 `/archive`에서 조회됨 | 목록·집계 전에 문서 가시성 검사 |

남은 색인 배치를 다음 호출에서 처리하는 검사는 통과했다. 검수 중 Claude의 동시 수정으로
이 경로가 보완됐으며, 예외 재시도와는 별개다.

후속 보완(C-182, 로컬): 이동 후보가 양쪽 모두 하나일 때만 문서 ID를 유지하고,
불변 파일도 origins의 후속 문서 연결을 반영한다. 변경 파일의 재처리 목록에도 최신 연결을
전달한다. 이 두 항목의 strict xfail을 해제했다. 해시 기반 동일 원본 확인은 아직 미구현이며,
잠금·재시도·시험 실행·개인 첨부 가시성 문제는 미해결이다.

## 추가 검수 필요

- 업로드 완료 기록이 문서 ID만 기준이다. 같은 ID의 원본 변경·폴더 변경·새 버전을 구별해야 한다.
- DGX 전송 성공뿐 아니라 원본 해시·크기와 DB 버전이 일치해야 보관 완료로 표시한다.
- 그래프 변경 감지가 문서 수·최대 ID·조각 수에 의존한다. 같은 건수의 내용·분류 변경도 반영해야 한다.
- 수정 원본 재처리 전에 장부가 최신으로 갱신된다. 전송·처리 실패가 다음 회차의 변경 목록에서
  사라지지 않도록 발견 버전과 처리 완료 버전을 구분해야 한다.
- 원본 보관·본문 처리·검색 색인·그래프의 완료 상태를 분리한다. 일부 완료를 전체 완료로 표시하지 않는다.
- 삭제·접근 권한 변경은 검색·그래프에 반영하되 원본 물리 삭제는 별도 보존 정책으로 처리한다.

수신 확인·운영 배포·실제 DGX 원본 대조는 아직 확인하지 않았다.
