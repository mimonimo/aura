# 구글 드라이브 체계 — 계정·부서·프로젝트가 많아질 때

작성 2026-09-24. 사용자 요구: 나중에 계정이 여럿, 부서마다 각자 계정으로 쓸 규모가 돼도 문제가 없어야 한다.

## 누구 드라이브에 만드나

- 플랫폼 계정마다 구글 계정을 하나 잇는다. 원천 관리에서 "구글 계정 허용"을 누른 사람에게 그 구글 계정이 자동으로 묶인다
  (`settings google_account:<플랫폼 계정>`). 문서는 그 사람의 드라이브에 만들어진다.
- 부서 공용 계정이 있으면 `google_account_dept:<부서>` 에 두면 묶이지 않은 담당자도 그 계정으로 만든다.
- 허용 계정이 하나뿐일 때는 누구나 그 계정을 쓴다(지금 단계).

## 어디에 두나

- `ZZAIMY/<연도>/<프로젝트 이름>/` — 대화가 프로젝트에 속할 때. 같은 프로젝트는 같은 폴더.
- `ZZAIMY/<연도>/기타/` — 프로젝트 없는 대화. 대화마다 폴더를 만들면 드라이브가 어지러워진다.
- 부서 공용 자리(공유 드라이브나 공유 폴더 id)를 `google_root:<부서>` 에 두면 위 경로가 그 아래에 만들어진다. 담당자가
  바뀌어도 문서가 개인 드라이브에 갇히지 않으려면 부서마다 이 값을 두는 것이 맞다(학교 워크스페이스 관리자가 공유 드라이브를
  만들어 주면 그 id).

## 나중에 프로젝트로 옮길 때

- 대화를 프로젝트에 넣으면(`POST /chat/{id}/project`, 또는 채팅으로 "이 문서를 ○○ 프로젝트로 옮겨 줘") 이어진 드라이브
  문서가 프로젝트 폴더로 옮겨진다. 프로젝트에서 빼면 기타로 돌아간다.
- 문서 이름은 채팅으로 바꾼다("문서 이름을 사업명으로 바꿔 줘"). 드라이브 파일 이름과 독스 제목, 대화 제목이 함께 바뀐다.

## 권한과 기록

- 플랫폼이 만든 파일만 옮기고 이름을 바꾼다(drive.file). 사용자의 다른 파일은 읽기 전용 범위로만 본다.
- 문서 쓰기·이름·이동은 `gdocs_audit.jsonl` 에 남는다. 열람 등급(부서·담당자 한정)은 플랫폼 문서에 걸리는 것이고, 드라이브
  문서의 공유는 구글 쪽 규칙을 따른다 — 부서 공용 자리를 쓰면 구글 공유가 부서 단위로 정리된다.

## 아직 못 하는 것

- 그림 삽입: 구글 독스 API 는 외부에서 접근 가능한 그림 주소만 받는다. 교내망의 그림은 드라이브에 올려 링크 공유 뒤 넣는
  경로가 필요하다(다음 일).
- (2026-09-30 해결) 사용자 관리 화면에서 이음을 보고 바꾼다 — 아래 갱신 절.

## 2026-09-30 갱신 — 사용자마다 학교 계정 연결, 관리자 화면

- 구글 앱(OAuth 클라이언트)은 개발자 계정이 한 번 등록한다(문서 가져오기 → Google 앱 설정). 사용자마다 따로 받을 것은 없다.
- 관리자는 개발자 허브 → 운영 도구 → 사용자 관리(/dev/users)에서 플랫폼 계정을 만들고(아이디·이름·역할·부서·초기 비밀번호),
  사용 중지·비밀번호 초기화를 한다. 같은 화면에서 누가 어느 구글 계정에 이어졌는지, 문서를 실제로 어느 계정으로 만드는지 본다.
- 사용자는 설정 → 내 구글 계정 → 구글 계정 연결로 자기 학교 계정을 허용한다. 구글 허용은 계정 주인만 할 수 있어서 관리자가 대신
  허용하지 못한다. 관리자는 이미 연결된 계정으로 다시 지정하거나 연결을 풀 수 있다.
- 허용 도메인은 기본 ync.ac.kr 이다. 허용 화면에 그 도메인 계정만 보이고(hd), 다른 도메인 계정으로 허용하면 토큰을 버리고
  구글 쪽 허용도 거둔다. 사용자 관리 화면의 구글 연동 설정에서 바꾼다.
- 미연결 사용자의 공용 계정 사용(허용 계정이 하나뿐일 때 그것으로 문서를 만드는 예전 동작)은 켜고 끌 수 있다. 사용자마다
  본인 계정을 잇게 되면 끈다.
- 부서 공용 계정과 부서 공유 드라이브 폴더(주소나 id)도 같은 화면에서 정한다.
- GCP 콘솔의 OAuth 동의 화면은 사용자 유형 '내부'가 맞다(ync.ac.kr 계정만 쓰므로 심사·7일 만료가 없다). 그러려면 프로젝트가
  ync.ac.kr 조직 아래에 있어야 한다 — 현재 설정은 미확인.
- 아이디에는 점을 쓸 수 없다(세션 토큰이 '만료.아이디.서명' 꼴).
