# 외부 전송 경로 목록과 통제 점검

작성 2026-10-15. `src/`·`scripts/`·화면 템플릿에서 네트워크로 나가는 호출을 전수로 찾아 정리했다. 기준은 ADR-0044(내부 활용은
원문, 학습·외부 전송 사본은 가림), ADR-0032(학교 워크스페이스 드라이브까지는 올린다), ADR-0038(외부 검색), ADR-0061(외부 판독
폐기), `docs/notes/2026-09-24-data-retention.md` 다.

교내 경로는 토르 02·03(vLLM, 임베딩·리랭커 서비스), DGX(Ollama·원본 보관), 운영 VM 안 서비스(Label Studio 등)다. 그 밖으로 나가는
것을 외부 전송으로 본다. 학교 구글 워크스페이스는 학교 계정 안이지만 교내망 밖(구글 서버)이므로 따로 표시했다.

운영 VM 의 실제 연결 설정(외부 서버 연결의 등록·지정 여부)은 이번 점검 때 접속이 되지 않아 미확인이다. 아래 판단은 코드 기준이다.

## 집계

앱(`src/`) 네트워크 경로 22개(표의 마지막 두 줄은 네트워크를 쓰지 않음을 확인한 것), 화면(브라우저) 경로 2개, 스크립트 묶음 7개, 모두 31개.

- 교내망 밖으로 나갈 수 있는 앱 경로 15개: 외부 LLM 연결 관련 5, 웹 검색 4, 구글 연동 6(OAuth·업로드·독스 쓰기·공개 권한·자동 가져오기·폴더 탐색)
- 교내 경로 7개: 교내 LLM·임베딩·리랭커·상태 확인·질의 확장/LLM 리랭커(교내 주소 전제)·Label Studio·DGX 원본
- 이번에 고친 빈틈 6개, 결정이 필요한 항목 6개

## 이번에 고친 것

1. 외부 LLM 연결의 공통 관문(`generate/outbound.py`): 외부 서버 연결로 만든 클라이언트는 모든 생성 요청이 이 관문을 지난다.
   개인정보를 `[[KR_PHONE_1]]` 꼴 토큰으로 바꿔 보내고, 답(조각 응답 포함)의 토큰은 교내에서 원값으로 정확히 되돌린다. 가림 도구가
   없거나 실패하면 보내지 않는다. 그림 조각은 보내지 않는다. `with_options` 사본에도 같은 관문을 씌운다.
2. 반입 검토·이미지 판독이 외부 기본 연결로 넘어가지 않는다. 용도를 비워 두면 교내 경로로 간다.
3. 외부 연결에는 토큰 세기(`/tokenize`)로 원문 메시지를 보내지 않는다.
4. 구글 열람본 만들기(`/api/doc/{id}/google`)와 작업본 연결이 열람 검사를 거친다.
5. 외부 검색: 질문 검사기를 준비하지 못하면 보내지 않는다. `ZZAIMY_WEB_SEARCH=off` 로 끈다. 구글 검색 키를 주소 대신 머리글로 보낸다.
6. 드라이브 공개 권한 닫기 실패를 경고로 남긴다.

검증은 `tests/test_egress_controls.py` 와 전체 테스트다.

관문의 가림은 정규식·인식기 기반이라 라벨 없는 이름·주소는 놓칠 수 있다. 외부 서버 지정 때의 개인정보 검토 확인을 대신하지 않는다.
외부 기본 연결에서 그림을 읽는 일(채팅 첨부 그림 등)은 이제 막힌다.

## 결정 필요

1. 외부 기관 GPU 서버 연결(`partner`)을 남길지. 관문을 넣었지만 문서 본문의 나머지(가림 대상이 아닌 기관 내부 정보)는 나간다.
   ADR-0061 이 ADR-0017 재결정 때 판단하기로 미뤄 두었다. 운영에 외부 연결이 등록돼 있는지는 미확인이다.
2. 구글 독스에 쓰는 글의 가림. ADR-0032 8항은 식별 번호(주민·계좌·사업자)를 가린다고 적었으나, ADR-0044 이후 코드는 내부 마스킹
   설정(기본 꺼짐)을 따른다. 그래서 지금은 식별 번호도 그대로 드라이브에 쓰인다. 학교 워크스페이스를 내부로 볼지, 식별 번호만은
   늘 가릴지 정해야 한다. 원본·변환본 업로드(원문)도 같은 판단에 걸린다.
3. 도식 넣기의 공개 창. 독스 API 가 공개 주소의 그림만 받아서 잠깐 '링크가 있는 누구나'로 연다. 짧지만 공개다. 다른 방법(교내 주소로
   그림 제공 등)을 쓸지 정해야 한다.
4. 화면의 바깥 자원(jsdelivr 글꼴, iconify 스크립트). 모든 화면에서 늘 불러오며, iconify 는 앱 화면 안에서 실행되는 바깥 스크립트다.
   정적 파일로 옮겨 자체 제공할지 정해야 한다.
5. `ZZAIMY_QUERY_EXPAND`·`ZZAIMY_LLM_RERANK` 는 관문 밖의 직접 클라이언트다. 기본 꺼짐이고 교내 주소 전제지만, 외부 주소를 넣으면
   질문·조각이 원문으로 나간다. 교내 주소만 받게 막을지 정해야 한다.
6. 외부 검색의 기본값. 키가 없어도 덕덕고로 동작하고 담당자 누구나 메시지마다 켤 수 있다. 끄는 설정은 넣었으나 기본을 꺼 둘지는
   정하지 않았다.

## 남은 점검

- 운영 VM 의 연결 설정·환경변수(외부 연결 등록 여부, 웹 검색 키, 질의 확장·LLM 리랭커 켜짐 여부) 확인. 이번에는 접속하지 못했다.
- 모델 화면의 용도 표는 비워 둔 용도를 「기본 연결」로 보여 준다. 기본 연결이 외부일 때 검토·판독은 교내 경로로 간다는 점은 화면에 아직 없다.
