# 파일럿 계획

> 상태: 작성됨 — 승인 대기 (P1 산출물, 브리프 9장 4번)
> 범위 고정: 최근 3~5년 유사 유형 사업의 계획서 20~30건 + 대응 결과보고서.
> 수만 장 전체로 시작하지 않는다 (절대 규칙 7).

## 1. 대상 선정 — 상태: 미결 (담당자 지정 필요)

구체 사업명은 사용자만 안다. 선정 기준을 여기서 확정하고, 목록은
담당자가 채운다 (W2까지):

1. 결과보고서가 대응 존재할 것 — 실적 카드의 원천 (③ 계열이 최우선 가치)
2. 최근 3~5년 내 — 문서 양식·용어의 현재성
3. 목차 구조가 유사한 사업 유형으로 묶을 것 (질문 #13 — Writer 섹션 매핑 난이도)
4. 선정/미선정이 섞여 있으면 표기 (질문 #14 — 평가셋 설계 활용)
5. HWP 원본 존재 여부 표기 (질문 #1 — 파서 경로 분기)

## 2. 마일스톤과 성공 기준 (capstone-plan §3과 정합)

| 시점 | 마일스톤 | 성공 기준 (정량) |
|---|---|---|
| W2 | 파일럿 목록 확정 + 표본 30~50p 수령 | 파서 bake-off 실행 완료 (TASK-09), 파서 확정 ADR |
| W3~W5 | 파일럿 전량 파싱·마스킹·인덱싱 | 전 문서 인덱스 적재, PII 감사 로그 무결, 평가셋 v1 동결 |
| W6~W8 | 실적 카드 DB + 베이스라인 | 검수 승인 카드 수백 건, 베이스라인 리포트 확정 |
| W9~W10 | 실공고 1건 end-to-end | 출처 주석 초안 1건 + 배점 커버리지 보고서 출력 |
| W11~W12 | 모델 4종 개선폭 | 베이스 대비 재현 가능 측정 완료 |

각 마일스톤 미달 시의 축소 순서: 모델 반복 횟수 축소 → Writer 비교군 축소 →
(최후) Extract를 교사 모델 운용으로 대체. 베이스라인 게이트와 평가셋 동결은
축소 대상이 아니다.

## 3. 수직 슬라이스 (TASK-08, 발표 시연의 백업)

- 범위: 공고 1건 · 문서 5~10건 · 섹션 1개 — end-to-end 선관통.
- 품질보다 경로. 각 단계는 스텁 허용하되 검증기 3종의 인터페이스는 진짜로 설계.
- 명령 한 줄로 공고 → 출처 주석 문단 1개가 나오면 성공.
- 발표회에서 전체 시스템이 미완이어도 이 슬라이스가 시연 백업이 된다.

## 4. 발표회용 비식별 데모 세트 (capstone-plan §1.2)

- W2에 대상 사업·연도를 확정한다 — 상태: 미결 (파일럿 목록과 함께 지정).
- Presidio 비식별화 통과본만 사용하고, 발표 전 육안 검수를 1회 더 거친다.
- 화면에 띄우는 모든 문서·수치는 데모 세트에서만 가져온다.
- 학생 노출 정책과 동일 기준 적용 (질문 #15 답변: 비식별화 통과본만).
