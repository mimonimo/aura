# OCR 시각 비교

동일 PDF 페이지를 이미지로 변환해 MinerU·Docling·Writer 비전의 판독 결과를 비교한다.
원본 이미지, 추출 원문, 실패, 소요 시간, 원본 SHA-256, 패키지 버전과 실행 설정을 보관한다.
원본과 추출 결과를 분리해서 표시하므로 원본 배경이 판독 오류를 가리지 않는다.

## 실행

엔진이 설치된 별도 시험 환경에서 실행한다. 운영 반입을 재시작하거나 색인을 수정하지 않는다.

```sh
PYTHONPATH=src .venv/bin/python scripts/172_ocr_visual_review.py --pdf /내부/시험문서.pdf --pages 2,7,15 --engines mineru,docling --settings-note '장비·백엔드·언어·모델 버전 등 실제 설정' --out data/eval/ocr-visual/새실행명
```

`report.html`은 이미지가 포함된 독립 보고서이며 브라우저에서 열고 캡처하거나 PDF로 인쇄한다.
`report.json`은 원본 이미지와 추출 결과를 포함한 대조 기록이다. 기존 출력 디렉터리는 덮어쓰지 않는다.
Writer는 `--engines vision`으로 지정할 수 있으며 실제 모델·연결 설정을 기록해야 한다.
엔진 실패나 빈 결과가 있으면 보고서를 남기고 종료 코드 1을 반환한다.

보고서는 원문을 포함한다. 접근이 제한된 내부 저장소에 보관하고 Git·공개 페이지에 올리지 않는다.
설정 메모에 토큰·비밀번호를 넣지 않는다. 오류 메시지에도 내부 경로가 포함될 수 있다.

## 검증 범위

- 원본 페이지 번호와 실제 입력 이미지를 유지한다. 추출문은 HTML로 실행하지 않고 문자로 표시한다.
- 표는 기존 171 비교 어댑터가 반환하는 셀 텍스트다. 표 구조 렌더링·좌표 강조·자동 표 채점은 아직 없다.
- 원본 글자층은 참고 자료이며 실제 스캔의 정답을 대신하지 않는다. 점수·채택 판정은 자동 생성하지 않는다.
- 단일 페이지를 이미지로 만든 시험이다. 디지털 PDF 직접 추출·문서 전체의 읽기 순서·처리량과 구분한다.
- 시간에는 각 엔진 호출의 초기화 비용이 포함될 수 있다. 메모리 측정과 반복 실행 통계는 별도다.
- 실제 엔진 비교 결과는 실행 후 검수한다. 구현 검증에 사용한 합성 화면은 성능 근거가 아니다.
