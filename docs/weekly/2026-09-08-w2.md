# 주간 개발 보고 — 2주차 (2026-09-01 ~ 09-08)

## 요약

이번 주는 운영 기반을 교체하고 시스템의 뼈대를 완성한 주였다. 운영 서버를
학과 가상서버(VM)로 이전해 상시 가동 체계를 만들었고, 검색 품질을 리랭킹
도입으로 끌어올렸으며, 미팅에서 확정된 방향(Qwen3.8-27B, SFT+DPO+RAG
하이브리드, 온톨로지 기반 학습 순환)에 맞춰 지식 그래프, 학습 데이터 변환
도구, 외부 참조 안전 관문을 모두 가동 상태로 올렸다. GPU 서버 확보 전에
할 수 있는 준비는 대부분 마친 상태다.

## 주요 성과

- 운영 서버를 학과 가상서버로 이전해 상시 가동 체계를 갖췄다. 재부팅에도
  스스로 복구되며(systemd 자동시작), 외부 인터넷이 차단된 환경에서 모델
  캐시로 자립 동작한다.
- 검색에 리랭커(bge-reranker-v2-m3, 후보를 다시 정렬해 정답을 위로 올리는
  모델)를 도입해 첫 번째 결과가 정답인 비율(Recall@1)이 0.49에서 0.62로,
  정답 순위의 역수 평균(MRR)이 0.62에서 0.72로 개선되었다.
- 지식 그래프 1단계를 구축했다. 기준 문서·접수 문서·프로젝트를 점으로,
  근거·소속·조문 참조·임베딩 유사를 선으로 잇는 구조 그래프를 만들고,
  화면에서 끌어보며 탐색하는 그래프 뷰를 플랫폼에 탑재했다. 경량 온톨로지
  (개체·관계 유형 정의)를 설계 기록(ADR-0009)으로 남겼다.
- 학습 데이터 변환 도구(데이터 공방)를 만들었다. 플랫폼에 쌓인 검토 의견·
  초안·대화 기록을 학습용 형식(JSONL)으로 변환하며, 출력의 모든 수치가
  입력 근거에 존재하는지 검증해 통과한 쌍만 내보낸다 — 모델이 수치를
  외워서 지어내는 것을 데이터 단계에서 차단하는 장치다.
- 외부 참조 안전 관문(이그레스 게이트웨이)을 완성했다. 외부 AI에 질의할 때
  개인정보·기관 식별자를 지우고(세척), 잔여 위험을 판정해 안전한 것만
  자동 전송하며, 애매한 것은 담당자 승인을 거치고 전 건을 감사 기록으로
  남긴다.
- 문서 속 표의 복원 품질을 구조적으로 개선했다. 디지털 PDF는 원본에 든
  괘선 좌표와 글자층을 직접 읽어 표의 병합·열 폭·텍스트를 원본 그대로
  복원한다(괘선 직독). 실물 공고문 검증에서 OCR 오인식("직계존속정"보")이
  사라지고 원본과 같은 칸 비율로 복원됨을 확인했다.
- 품질 관리 체계를 5계층(원천 차단, 자기 검증, 회귀 테스트, 지표 추적,
  담당자 신고 루프)으로 명문화하고, 문서 화면에 추출 문제 신고 기능을
  붙였다. 자동 테스트는 210건이 통과 상태다.

## 문제와 대응

- 표 추출이 원본 서식과 다르게 나오는 문제가 실물 공고문에서 발견되었다.
  원인은 OCR이 표를 근사 격자로 재구성하는 방식 자체였고, 특정 문서를
  고치는 대신 디지털 PDF의 처리 경로를 괘선 직독 방식으로 교체해 같은
  부류의 문제를 원천 차단했다. 재발 방지 테스트를 함께 넣었다.
- 서버 이전 후 재색인 스크립트가 옛 장비 기준 설정(인터넷 접근 가정)으로
  남아 있어 시간을 허비하는 문제가 있었다. 오프라인 강제, 코어 절반 사용,
  동시 실행 방지를 스크립트에 박아 운영 결함도 구조로 차단했다.
