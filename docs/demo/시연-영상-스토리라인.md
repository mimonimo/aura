# AURA 결과물 시연 영상 스토리라인

제출: 11월 8일 이전. 길이 목표 6~8분(자막, 기다리는 구간은 배속).
촬영: 운영 플랫폼(https://aura.ync.ac.kr)에서 시연용 교직원 계정으로 실제 작업을 처음부터 끝까지 진행하고, 화면 녹화와 장면별 사진을 함께 남긴다.
예시 프로젝트는 가상 사업이다. 근거 자료는 공개 공고문·기본계획만 쓰고, 실물 내부 문서는 화면에 띄우지 않는다.

## 이야기 한 줄

기획처 담당자가 내년 AI 교육 사업 계획서를 써야 한다. 빈 프로젝트에서 시작해 공고를 올리고, AURA 에게 말로 부탁하면
로컬 27B 에이전트가 근거를 찾고, 한글 양식을 설계하고, 절을 나눠 쓰고, 수치를 점검해 한글 파일까지 만든다.
중간에 규정 질문을 던지면 출처 조항과 함께 계산까지 해 준다.

## 촬영 규칙

- 계정·비밀번호·내부 IP 는 화면과 자막에 넣지 않는다(로그인 장면은 입력 칸을 비워 둔 채로).
- 실물 내부 문서·개인정보가 보이는 화면(원본 보관소, 개발 화면)은 찍지 않는다.
- 기다리는 구간(27B 생성)은 잘라 내지 않고 배속으로 보여 준다. 화면에 걸린 시간을 자막으로 적는다.
- 사진은 장면마다 1~3장, 파일 이름은 장면 번호로 시작한다(예: 06-양식-설계-완료.jpg).
- 녹화 원본·사진·편집본은 바탕화면 AURA-시연영상 폴더에 둔다. 저장소에는 이 스토리라인만 둔다.
