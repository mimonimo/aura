## 해석 (2026-09-20, Claude)

- 이 질의 세트에서는 어떤 리랭커도 하이브리드 순위를 이기지 못했다. 차이는 150문제 중 서너 문제 이내라
  통계적으로 의미 있는 차이로 보기 어렵다. R@10 은 모두 0.740 — 후보 상위 10 밖의 정답은 리랭커가 구할 수 없다.
- 합성 질의는 정답 조각의 글에서 만들어 어휘 겹침이 커 하이브리드에 유리하다. 비슷하게 관련된 다른 조각을
  1위로 올리면 오답으로 센다. 운영 순위 방식은 이 결과만으로 바꾸지 않는다.
- 크로스인코더는 VM CPU 에서 질의당 4.4초다. 순위 이득이 없다면 비용이 크다. 대신 '근거가 약함' 판정
  (무관 질의 0.002~0.03 대 관련 질의 0.68~0.98)에 쓰임새가 있다 — 하한 보정은 별도 측정.
- 다음: 실제 담당자 질문으로 만든 평가 세트(채팅 기록 + 사람 판정)가 필요하다. 추출 좌표 수정 뒤 2차 평가는
  야간 체인 2 가 이어서 잰다.
