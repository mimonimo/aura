# 평가 계획

> 상태: **미작성** — P1 산출물 (브리프 9장 3번)
> 근거 문서: `research/01-L-evaluation.md`

브리프 5.5: 베이스라인 없이 파인튜닝하면 개선을 주장할 수 없다.
축 B의 성과 입증 전체가 이 문서에 달려 있으며, 논문 실험 섹션의 골격이기도 하다.

## 작성해야 할 것

- [ ] 평가셋 구축 방안 — 문항 수, 정답 기준, 사람 검수 절차
- [ ] 검색 지표 — Recall@k · MRR · nDCG
- [ ] 생성 지표 — 평가지표 반영률 · **수치 환각률(0 수렴)** · 문체 적합성
- [ ] 추출 지표 — 필드별 F1 · 처리량 배수
- [ ] 베이스라인 측정 절차 (재현 가능해야 함)

## 하네스

자체 IR 하네스(pytrec_eval) + DeepEval(로컬 저지). 사람 블라인드 평가 병행.
