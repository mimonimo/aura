# 이전 측정 보고서 — LLM 리랭킹·질의 확장 회차별 결과 (2026-09-20)

> 지난 기록 — 지금은 「리랭커 평가(9/20)」(../llm-rerank-eval.md)와 「ZZAIMY-Rerank v1 모델 카드」(../model-cards/zzaimy-rerank-v1.md)

[리랭커 평가](../llm-rerank-eval.md)에 이르기까지 같은 날 돌린 중간 회차다. 회차마다 따로 있던 보고서 여덟 편을 한 문서로 묶었다.
모든 회차는 질의 150건(고정 시드 7 표본)이고, 같은 하이브리드 후보 상위 10을 재정렬한다. paraphrase 는 상황 질문,
synth 는 정확한 질문 표본이다. 각 표는 그 회차의 측정 날짜·데이터·모델 기준으로 읽는다. 원자료는 회차마다 적힌
`data/eval/` 파일이고 산출은 `scripts/90_llm_rerank_eval.py` 다.
