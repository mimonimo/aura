# 중간 발표 PPT 자료 모음

2026-10-18 기준. 앞쪽 「플랫폼 기능 전체 지도」로 무엇을 만들었는지 한 장씩 잡고, 뒤쪽은 중간 발표자료 절 순서대로 장마다 넣을 수치·표·화면이다.
수치는 「어디서」 화면에서 그대로 읽은 값이고, 화면 캡처는 발표 자료 폴더(화면)에 번호 붙은 파일로 있다. 설명 문장은 구현 설명서(같은 화면)를 따른다.

## 장별 구성 (중간 발표자료 절 순서)

### 1. 프로젝트 개요
- 그림: 시스템 구성도 `10_시스템구성도.svg` 또는 `01` 의 「시스템 구성」
- 한 줄: 교내 행정 문서를 데이터로 만들어, 근거를 짚는 답과 사업계획서 초안을 교내 장비에서 만든다

### 2. 기획 단계 계획
- 제안서 계획표(9-1 ~ 12-1)와 기술 선택 이유 — 중간 발표자료 2절

### 3. 현재 진행 상황
- 진척도 표(활동 15개) — 중간 발표자료 3절. 전체 약 73%, 계획상 지금까지 몫 약 52%
- 그림: `01` 아래 「영역별 완료 비율」

### 4. 중간 결과물
- 데이터 규모: 학교 원본 35,467 · 라이브러리 35,469 · 조각 1,848,580 · 벡터 1,586,051 · 규정 조각 9,595 · 지식그래프 노드 41.6만·관계 58.4만 · 사업 장부 96
- 비교 실험(같은 시험지 — 절 질문 73 · 관계 질문 75 · 답 36, `08`):

| 지표 | 풀텍스트 RAG | GraphRAG(운영) | 차이 |
|---|---|---|---|
| 특정 문서의 한 부분을 묻는 질문 — 그 문서가 상위 5건에 | 18% | 70% | +52%p |
| 관계를 묻는 질문 — 양쪽 문서가 모두 상위에 | 13% | 45% | +32%p |

| 답 채점 평균(0~2점, 방식 가리고 매김) | 0.361 | 0.917 | +0.56 |

- 속도·근거 개선(기준 측정, 실험 기록 14~17절):

## 캡처할 때 주의
- `14` 표에 실제 산업체 인사 이름이 보인다 — 발표에 쓸 때는 그 칸을 가린다
- 대화 목록·사용자 계정처럼 개인 이름이 보이는 화면은 쓰지 않는다
- 업무 도우미 창과 구글 드라이브 양식 화면은 팝업·외부 화면이라 직접 캡처한다
- 숫자는 화면에서 마우스를 올리면 무엇을 셌는지 나온다 — 질문이 나오면 그 설명을 그대로 읽으면 된다
