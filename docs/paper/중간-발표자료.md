# 중간 발표자료 구성안

정리 2026-09-15: 장비를 운영 가상서버+GPU 서버 구성으로, 검색 수치를 정본 리포트(retrieval-baseline-mini·rerank-baseline, 2026-09-04, 합성 질의)와 일치시켰다(이전의 Recall@1 0.583·Recall@10 0.871·질의 2,478건은 출처 없음). 구축 현황에 지식 그래프·외부 참조 관문·한글 에이전트를 반영하고, 검색 모델 학습은 리허설(홀드아웃 96질의, 베이스 미달)로 정정했다. 배점 커버리지의 의미 판정(ADR-0015)을 검증기 슬라이드에 반영했다. 시연 문서의 쪽수(103쪽)는 출처가 없어 뺐다.

발표 양식이 확정되기 전의 슬라이드 구성 초안이다. 각 절이 슬라이드 한 장에
해당하며, 지표 수치는 발표 시점의 최신 측정값으로 갱신한다. 수치의 정본은
`논문-원재료.md` 6절 수치 총람과 거기 적힌 리포트다.

## 1. 프로젝트 소개

- 교내 행정업무 자동화를 위한 YNC sLLM 플랫폼 「짜이미(ZZAIMY)」
- 문제의식: 행정 문서는 외부 AI에 올릴 수 없다 — 개인정보·내부정보
- 해법: 교내 장비(운영 가상서버 + GPU 서버) 위에서 도는 소형 언어모델 시스템.
  완성본이 아니라 70% 초안과 근거를 내고 담당자가 검수한다

## 2. 시스템이 하는 일 (데모 흐름)

- 문서 읽기: 스캔본·사진을 원본 모습 그대로 검색되는 전자문서로 복원
- 규정 응답: 질문하면 등록된 규정에서 근거 대목을 찾아 답변
- 초안 작성: 공고의 작성 항목에 맞춘 계획서 초안을 한글(HWPX)·워드·PDF로
- 검증: 초안의 수치·예산·배점 반영을 검증기가 재확인
- 문서 연관: 기준 문서·접수 문서 사이의 연관을 지식 그래프로 탐색

## 3. 구축 현황 (2026-09-15)

- 완료: 문서 복원 파이프라인, 하이브리드 검색 + 리랭커, 검증기 3종, 초안
  4형식 출력(docx·pdf·md·hwpx), 담당자·개발자 계정 분리, 지식 그래프 1단계,
  외부 참조 관문(이그레스 게이트웨이), 한글 편집 에이전트(실장비 검증),
  개발자 대시보드·PII 점검 화면, 운영 가상서버 상시 가동
- 진행: 개체 수준 그래프 2단계, 검색 모델 추가 학습 실험(리허설 2회), 초안
  그림 삽입
- 대기: GPU 서버(DGX) 확보 → 생성 모델 서빙 → 베이스라인 측정, 교내 실물
  문서 파일럿(표본·개인정보 검토)

## 4. 핵심 결과 1 — 문서 복원

- 디지털 PDF는 글자 좌표를 직접 읽어 원문 무손실, 스캔은 화질 보정 + OCR
  투명 글자층(ADR-0007)
- MinerU OCR 어절 F1 0.74~0.84(디지털 PDF 렌더를 스캔처럼 처리, 문서 5건,
  운영 서버 CPU — ocr-cer-bench)
- 시연: 디지털 PDF 실물 문서와 스캔 문제집(12쪽)의 복원 전후 비교 화면

## 5. 핵심 결과 2 — 규정 검색 정확도 (합성 질의, 2026-09-04 측정)

- 규정 조각 1,236개(측정 당시, 9/14 재분할 후 1,211개) · 합성 질의 2,595건.
  합성 질의 자가 검색이라 절대치는 낙관적이며 방식 간 비교용이다
- 한 번에 정답(Recall@1): 어휘 0.338 / 임베딩 0.611 / 하이브리드(임베딩 우세)
  0.595. 후보 10개 안(Recall@10): 임베딩 0.877 / 하이브리드 0.877~0.879
- 리랭커(bge-reranker-v2-m3, 표본 300건): 하이브리드 Recall@1 0.490 → 0.623,
  MRR 0.623 → 0.716
- 하이브리드는 설계상 구성(임베딩 + 키워드 이중 벡터화)이며 합성 세트에서는
  임베딩 단독과 동급. 개선 폭이 뚜렷한 것은 리랭커

## 6. 핵심 결과 3 — 검증기

- 원칙: 수치는 인출하고 생성하지 않는다
- 한국어 단위 동치 판정("6천만 원" = "60,000,000원"), 예산 곱셈 재계산 —
  LLM이 아닌 결정론 로직
- 배점 누락 검출 — 키워드 판정(결정론)에 임베딩 의미 판정을 더한 2단
  (ADR-0015). 합성 표본에서 키워드만 0/55점 → 45/55점, 판정 폭은 실제
  초안으로 재보정 예정

## 7. 정직한 실험 기록

- 검색 모델 추가 학습: 리허설(홀드아웃 96질의) 결과 베이스 미달(Recall@1
  0.271 → 0.219) — 미적용, 실데이터·층화 홀드아웃으로 재도전
- 외부 OCR 엔진 실물 대결: MinerU hybrid-engine·dots.ocr는 오독·환각 확인 후
  보류, PaddleOCR-VL은 CPU 서버에서 측정 불가(GPU 필요)
- 규칙 기반 연관 판정(개체 하나 겹침·키워드 포함)의 오분류를 실측하고
  학습된 임베딩 판정으로 전환(ADR-0015)
- 부정적 결과도 기록하는 것이 방법론의 일부

## 8. 남은 일정

- 교내 실물 문서 파일럿 → 골드셋 구축, 층화 홀드아웃 재측정
- GPU 서버 확보 → Qwen3.8-27B 서빙 → 베이스라인 측정 → SFT → DPO
- 모델 4종 학습(임베딩 재도전, 리랭커, 작성, 추출)
- 논문 작성과 최종 발표
