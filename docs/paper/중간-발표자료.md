# 중간 발표자료 구성안

발표 양식이 확정되기 전의 슬라이드 구성 초안이다. 각 절이 슬라이드 한 장에
해당하며, 지표 수치는 발표 시점의 최신 측정값으로 갱신한다.

## 1. 프로젝트 소개

- 교내 행정업무 자동화를 위한 YNC sLLM 플랫폼
- 문제의식: 행정 문서는 외부 AI에 올릴 수 없다 — 개인정보·내부정보
- 해법: 교내 장비(DGX Spark) 위에서 도는 소형 언어모델 시스템

## 2. 시스템이 하는 일 (데모 흐름)

- 문서 읽기: 스캔본·사진을 원본 모습 그대로 검색되는 전자문서로 복원
- 규정 응답: 질문하면 등록된 규정에서 근거 대목을 찾아 답변
- 초안 작성: 공고의 작성 항목에 맞춘 계획서 초안을 한글(HWPX) 파일로
- 검증: 초안의 수치·예산을 결정론 검증기가 재확인

## 3. 구축 현황

- 완료: 문서 복원 파이프라인, 하이브리드 검색, 검증기 3종, 초안 4형식 출력,
  담당자·개발자 계정 분리
- 진행: 검색 모델 추가 학습 실험, 초안 그림 삽입
- 대기: 교내 실물 문서 파일럿 (표본·개인정보 검토)

## 4. 핵심 결과 1 — 문서 복원

- 디지털 PDF는 원문 무손실, 스캔은 화질 보정 + OCR 투명 글자층
- 시연: 103쪽 장학 문서, 스캔 문제집의 복원 전후 비교 화면

## 5. 핵심 결과 2 — 규정 검색 정확도

- 규정 문단 1,236개 · 합성 질의 2,478건 측정
- 한 번에 정답(Recall@1): 임베딩 0.583 / 후보 10개 안(Recall@10): 하이브리드 0.871
- 키워드와 의미 검색을 합친 하이브리드 구성의 근거

## 6. 핵심 결과 3 — 검증기

- 원칙: 수치는 인출하고 생성하지 않는다
- 한국어 단위 동치 판정("6천만 원" = "60,000,000원"), 예산 곱셈 재계산,
  배점 누락 검출 — 전부 LLM이 아닌 결정론 로직

## 7. 정직한 실험 기록

- 검색 모델 추가 학습: 아직 기본 모델을 넘지 못함 — 미적용, 실데이터로 재도전
- 외부 OCR 엔진 2종 실물 대결: 오독·환각 확인 후 도입 보류
- 부정적 결과도 기록하는 것이 방법론의 일부

## 8. 남은 일정

- 교내 실물 문서 파일럿 → 층화 홀드아웃 재측정
- 모델 4종 확장 (리랭커·작성·추출)
- 논문 작성과 최종 발표
