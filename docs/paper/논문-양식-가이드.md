# 논문 양식 가이드 (2025 캡스톤 논문집 분석)


작년 논문집(사이버보안과) 실물에서 뽑은 형식 기준이다. 우리 논문도 이 틀에
맞춰 작성한다. 편수·쪽수와 한 편의 구성은 사용자가 논문집 실물을 다시 열람해
확인했다(10-24).

## 전체 구조

한 편이 학술지 논문이 아니라 프로젝트 보고서형 논문이다. 논문집은 8편 수록·672쪽이고,
한 편은 60~70쪽 분량이다(표본: 1번 논문 본문 시작 p9 → 참고 문헌 p77).

구성 순서(실물 한 편에서 확인):

1. 표지 — 머리에 「2025 ○○과 캡스톤디자인 졸업프로젝트 논문」, 그 아래 상자 안에
   PROJECT _ n, 프로젝트 제목, 팀원, [팀명]
2. 목차 — 1./1.1/1.1.1 세 단계, 점선 리더 + 쪽 번호
3. 그림 목차 — [그림 n-m] 장-번호 체계 (표가 있으면 표 목차도)
4. 1. 서론 — 1.1 프로젝트 배경 및 목적 / 1.2 핵심내용 / 1.3 기대효과 / 1.4 프로젝트 구성.
   1.4 에 [그림 1-2] 전체 프로젝트 구조 같은 구조도가 들어간다
5. 2. 관련 연구 — 영역별 묶음을 2.1, 그 안의 도구 하나하나를 2.1.1 처럼 소개한다.
   도구마다 로고를 그림으로 싣는다(예: [그림 2-3] ○○ 로고)
6. 3. 환경 구축 및 시스템 설계 — 3.1 환경 구축, 3.2 시스템 아키텍처 설계,
   3.2.1 전체 시스템 구성도 및 데이터 흐름
7. 4. 구현 — 기능별 절
8. 5. 결과 — 대시보드·시연 결과
9. 6. 결론 — 6.1 연구 요약 및 기여점 / 6.2 결과 평가 및 한계점 / 6.3 향후 연구 방향
10. 참고 문헌 — [n] 출처명. 제목 + URL 나열식
11. Abstract — 영문 초록
12. 팀원 소개

## 지면 형식

- 머리글: 오른쪽 위에 줄인 논문 제목
- 바닥글: 쪽 번호와 「영남이공대학교 ○○과」
- 그림·표 캡션: [그림 2-3], [표 3-1] 장-일련 체계, 캡션은 그림·표 아래
- 문체: "~한다/~이다" 서술형. "본 프로젝트의 핵심은 …이다",
  "…할 것으로 기대된다" 같은 표현 관례

## 우리 논문에의 적용

장 파일은 `docs/paper/논문/` 에 있고 목록과 진행 상태는 그 폴더의 README 가 관리한다.

서론의 배경과 목적은 브리프의 배경 장에서 가져온다. 온프레미스가 필요한 이유와 개인정보 제약이
그 내용이다. 핵심 내용은 축 A(플랫폼 전 경로)와 축 B(도메인 특화 개선)이고, 기대 효과는 사람이 검수하는
초안이라는 실사용 전제와 교내 행정 적용이다.

관련 연구는 쓰는 기술을 영역별로 묶어 하나씩 소개한다. vLLM과 젯슨의 NVFP4 양자화 서빙, 생성 모델 Qwen3.8-27B와
초기 검증에 쓴 Qwen3.5-35B-A3B, MinerU와 OCR, KURE 임베딩과 bge 리랭커 및 그 학습본, 하이브리드
검색과 RRF, Presidio 개인정보 마스킹, 지식 그래프와 온톨로지(OWL·SHACL), 한글 변환(kordoc·자체 hwpx 변환기)과 서식 보존 채우기,
웹 한글 기안기와 칸 단위 공동 편집, 구글 독스·드라이브 연동, SSE 가 각각 한 절이 된다.

설계 장은 아키텍처 문서와 결정 기록(ADR)이 재료다. 장비 분담은 ADR-0023에 있다. 구현 장은 실험
로그의 OCR과 복원 절, 검증기 세 종, 학습된 연관 판정(ADR-0015), 검색 학습본 채택(ADR-0020, 0021),
지식 그래프, 외부 참조 관문, 한글 완성본 산출, 데이터 공방, 반입 단계의 이름 규칙, 플랫폼 기능을
다룬다. 결과(평가) 장은 논문 원재료의 수치 총람과 그 정본 기록(검색 기준선과 현행 측정, 학습본 모델
카드, 임베딩 리허설의 부정 결과, 서빙 정밀도 비교, SFT 비교)과 실물 검증 사례, 대시보드·시연 화면을 쓴다.
결론과 향후 과제는 파일럿 계획과 원재료 9절의 한계에서 나온다. 참고 문헌은 조사 노트의 출처 목록이 그대로 재료다.
Abstract 와 팀원 소개는 참고 문헌 뒤에 둔다.

주의: 분량 관례가 60쪽대이므로 스크린샷·다이어그램(그림 목차 채울 것)을
구현 단계마다 캡처해 모아둬야 한다 — /dev 대시보드·복원 뷰·검증 결과 화면·
그래프 뷰 등. 관련 연구 장의 도구 로고도 그림으로 센다.
