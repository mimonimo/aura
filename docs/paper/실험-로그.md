## 실패·사고 기록 (방법론의 재료)

- 학습 SIGKILL 원인 규명 2건: (1) 통합메모리에서 트레이너 CUDA 초기화 OOM
  → CUDA_VISIBLE_DEVICES= 로 CPU 강제, (2) 학습 중 동시 GPU 작업(MinerU·별도
  서빙)이 커널 OOM 킬 유발 → 학습 단독 점유 규칙 확립
- 코퍼스 재구성 시 파생물 연쇄 무효화: 합성 질의 세트(chunk_id 기준)와
  임베딩 npz가 함께 무효 — "재구성 → 51 → 52 → 53" 체인 순서를 규칙화
- 디지털 PDF OCR 오판 실사고: MinerU auto가 103쪽 디지털 문서를 OCR로 읽어
  "기초과학→기추과하" — 텍스트 레이어 감지 라우팅으로 원천 차단

## OCR·복원 실험 (축 A 방법론)

- 복원 뷰 3안 비교(실물 렌더 검증): 블록 bbox 재구성(잘림·중복·왜곡 발생)
  → 글자 좌표 직독(pdfium charbox — 원리적 무오차, 단 표 괘선·서식 미표현)
  → 원본 렌더 배경 + 투명 텍스트 레이어(구글 OCR PDF 방식)로 확정.
  디지털=좌표 직독, 스캔=MinerU 줄 좌표(신뢰도≥0.5), 사진=보정 스캔+OCR 줄
- LLM 오타 교정의 게이트·범위 확장: 본문만 → 표 셀 포함, 라벨 기준 →
  실제 OCR 발생 기준. 행정 용어 사전 프롬프트로 맥락 없는 셀 교정률 개선
  ("주민등특번호→주민등록번호", "등의여부→동의여부" 실측 교정)
