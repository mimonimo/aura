# Abstract

University administrative documents such as government grant announcements, project plans, performance reports, and regulations contain personal
and internal information, so they cannot be sent to commercial cloud AI services, and staff have long had to find, read, and transcribe past documents
by hand. This project implements AURA, a platform that reads, retrieves, writes, and co-edits these documents using only on-campus hardware: one
operations server without a GPU, two NVIDIA Jetson AGX Thor devices for model serving, and one NVIDIA DGX for archiving originals, batch processing,
and training.

AURA makes four contributions. For document digitization, it reads digital PDFs, scanned documents, photos, Hangul (HWP and HWPX) files, and office
files while preserving table structure, and masks personal information with Presidio and eight Korean-specific pattern recognizers. For GraphRAG, it
organizes about 35,000 campus documents into a knowledge graph linking programs, program years, documents, and sections (the ontology is validated with
OWL and SHACL). The generation model Qwen3.8-27B, served with vLLM in NVFP4, interprets a question in ontology terms, narrows the search scope through
the graph, and then combines Kiwi lexical search and semantic search with reciprocal rank fusion (RRF). As a result, the share of section questions
whose correct document appears in the top five rose from 18% with full-text search to 70%. A reranker trained on campus documents raised R@1 from
0.649 to 0.711 on documents not used for training. Answers cite only the evidence given to the model, and code separately flags any number that does
not appear in the evidence. The document agent selects tools to write and revise sections and fills content into the original HWPX form while keeping
its formatting. In region-level co-editing, people and the agent edit one document together in the Hancom web Hangul editor, and the median delay
before a character typed on one screen appears on another is 221 ms.

Supervised fine-tuning (SFT) of the generation model is an experiment intended for application to larger models; the training procedure and data
were validated on the 27B model. Training on 4,434 pairs built from real campus documents raised answer overlap with references (chrF) on the test set
from 27.9 to 36.6 and reduced the share of answers containing numbers absent from the question from 4.1% to 0%. However, because the training pairs
followed a single format, the model also answered the agent's JSON requests in the trained format; for larger models, the platform's request formats
will be included in the training data. What AURA produces is a draft that staff review and complete.

Keywords: on-premise LLM, retrieval-augmented generation, knowledge graph, ontology, document agent, administrative documents, HWPX, co-editing
