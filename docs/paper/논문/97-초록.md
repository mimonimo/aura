# Abstract

대학 행정 문서(국고사업 공고, 사업계획서, 실적보고서, 규정 등)에는 개인정보와 기관 내부 정보가 들어 있어 상용 클라우드 AI 서비스에 보낼 수 없다.
그래서 담당자는 지난 문서를 직접 찾아 읽고 옮겨 적으며 새 문서를 작성해 왔다. 본 프로젝트는 이 일을 교내 장비만으로 돕는 플랫폼 AURA를
구현하였다. 문서는 학교 밖으로 나가지 않으며, 운영 서버 한 대, 모델 서빙 장비 두 대(NVIDIA Jetson AGX Thor), 학습 장비 한 대(NVIDIA DGX)로 동작한다.

AURA가 하는 일은 네 가지다. 첫째, PDF, 스캔 문서, 한글(HWP·HWPX), 오피스 파일 등 형식이 제각각인 교내 문서 약 3만 5천 건을 표 구조를 살려
읽고, 개인정보를 가린 뒤 검색할 수 있게 정리한다. 둘째, 사업·연도·문서·절의 관계를 지식 그래프로 묶어, 질문이 가리키는 사업과 문서를 먼저 찾은 뒤
그 안에서 근거를 검색한다. 이 방식으로 질문한 내용을 상위 5건 안에 찾아오는 비율이 일반 검색의 47%에서 93%로 높아졌고, 그 내용을 근거로 답한 비율은 100%였다. 답변은 찾은 근거만
인용하고, 근거에 없는 숫자는 따로 표시해 담당자가 확인하게 한다. 셋째, 문서 작성 에이전트가 담당자의 요청에 따라 양식을 고르거나 만들고, 절마다
초안을 작성하며, 원본 한글 서식을 그대로 둔 채 내용을 채운다. 작성을 마치기 전에는 문서를 다시 읽어 빈칸이나 잘못 들어간 표를 스스로 고친다.
넷째, 여러 담당자와 에이전트가 웹 한글 편집기에서 한 문서를 동시에 편집할 수 있으며, 한 사람이 입력한 글은 0.2초 안에 다른 사람의 화면에 나타난다. 이 모든 결과는 담당자가 검토해 완성하는 초안이다.

이와 별도로, 생성 모델(Qwen3.8-27B)을 교내 실제 문서로 만든 학습 데이터로 추가 학습하는 실험도 진행하였다. 학습 후 답변이 정답에 더 가까워지고 근거 없는
숫자를 쓰는 일이 사라졌으나, 에이전트가 단계마다 요구하는 JSON 형식에는 맞추지 못하는 한계가 드러났다. 이 결과를 바탕으로 학습 절차와 데이터를 정리해 두었다.

앞으로는 교직원이 실제 업무에 사용하는 시범 운영으로 효과를 측정하고, 더 큰 모델로 교체해 같은 학습 절차를 적용할 계획이다. 모델 이름과
문맥 길이를 설정으로만 바꾸도록 설계했으므로 코드를 고치지 않고 교체할 수 있다. 또한 다양한 문서 갈래의 양식을 더 익혀 작성할 수 있는 문서의
범위를 넓히고, 다른 대학과 기관에서도 같은 구조로 설치할 수 있도록 확장할 것이다.

주제어: 온프레미스 LLM, 검색 증강 생성, 지식 그래프, 문서 작성 에이전트, 행정 문서, 한글 문서, 공동 편집
