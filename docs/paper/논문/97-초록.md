# 초록

대학 행정은 국고사업 공고, 사업계획서, 실적보고서, 규정 같은 문서로 움직인다. 이 문서들에는 개인정보와 기관 내부 정보가 들어 있어
상용 클라우드 AI 서비스에 보낼 수 없고, 담당자는 지난 문서를 손으로 찾아 읽고 옮겨 적는다. 이 프로젝트는 교내 장비만으로 도는 문서 처리
플랫폼 AURA 를 만들었다. 장비는 GPU 없는 운영 서버 한 대, 모델 서빙용 NVIDIA Jetson AGX Thor 두 대, 원본 보관·일괄 처리·학습용 NVIDIA DGX 한 대다.

AURA 는 디지털 PDF, 스캔 문서, 사진, 한글(HWP·HWPX), 오피스 파일을 표 구조를 지키며 읽고, Presidio 와 한국어 전용 인식기로 개인정보를 찾는다.
검색은 Kiwi 형태소 분석 기반 어휘 검색과 의미 검색을 순위 융합(RRF)으로 합치고, 교내 문서로 학습한 KURE-v1 임베딩과 bge-reranker-v2-m3
리랭커를 쓴다. 사업·연차·문서·절을 잇는 온톨로지를 OWL·SHACL 로 검사해 노드 410,805 개·관계 575,452 개의 지식 그래프를 만들었다.
오픈 모델 Qwen3.8-27B 를 vLLM·NVFP4 로 서빙하고, 이 모델이 질문을 온톨로지 낱말로 읽어 그래프로 범위를 좁히자, 절 질문에서 정답 문서가
상위 5 개 안에 드는 비율이 전문 검색 18% 에서 70% 로 올랐다. 답은 모델에 건넨 근거만 인용하고, 근거에 없는 숫자는 코드가 따로 표시한다.
문서 작업 에이전트는 도구를 골라 절을 쓰고 고치며, 원본 HWPX 서식을 깨지 않고 채우고, 웹 한글 기안기에서 사람과 칸 단위로 함께 편집한다
(글자당 지연 중앙값 221ms).

산출물은 담당자가 검토해 완성하는 초안이며 그대로 제출하는 완성본이 아니다. 지도 학습(SFT)한 작성 모델은 학습 꼴의 지표는 나아졌으나
에이전트 흐름을 무너뜨려 채택하지 않았고, 이 결과를 평가 절차와 함께 적었다.

주제어: 온프레미스 LLM, 검색 증강 생성, 지식 그래프, 온톨로지, 문서 작업 에이전트, 행정 문서, HWPX, 공동 편집
