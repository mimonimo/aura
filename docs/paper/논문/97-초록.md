# 초록

국고사업 공고, 사업계획서, 실적보고서, 규정 같은 대학 행정 문서에는 개인정보와 기관 내부 정보가 들어 있어 상용 클라우드 AI 서비스에 보낼 수 없고,
담당자가 지난 문서를 직접 찾아 읽고 옮겨 적어 왔다. 본 프로젝트는 교내 장비만으로 문서를 읽고 검색하며, 작성하고 함께 편집하는 플랫폼 AURA를 구현하였다.
장비는 GPU가 없는 운영 서버 한 대, 모델 서빙용 NVIDIA Jetson AGX Thor 두 대, 원본 보관·일괄 처리·학습용 NVIDIA DGX 한 대다.

AURA의 기여는 네 가지다. 문서 데이터화는 디지털 PDF, 스캔 문서, 사진, 한글(HWP·HWPX), 오피스 파일을 표 구조를 보존하며 읽고, Presidio와 한국형 패턴
인식기 8종으로 개인정보를 마스킹한다. GraphRAG는 교내 문서 약 3만 5천 건을 사업·연차·문서·절을 잇는 지식 그래프로 구성하고(온톨로지는 OWL·SHACL로 검사),
vLLM과 NVFP4로 서빙하는 생성 모델 Qwen3.8-27B가 질문을 온톨로지 용어로 해석해 그래프로 검색 범위를 좁힌 뒤 Kiwi 어휘 검색과 의미 검색을 순위 융합(RRF)으로 결합한다.
그 결과 절 질문에서 정답 문서가 상위 5건 안에 드는 비율이 전문 검색의 18%에서 70%로 올랐다. 교내 문서로 학습한 리랭커는 학습에 사용하지 않은 문서에서
R@1을 0.649에서 0.711로 높였다. 답은 모델에 제공한 근거만 인용하며, 근거에 없는 숫자는 코드가 따로 표시한다. 문서 작업 에이전트는 도구를 선택해 절을
작성·수정하며, 원본 HWPX 서식을 유지한 채 내용을 채운다. 영역 단위 공동 편집에서는 사람과 에이전트가 웹 한글 기안기에서 한 문서를 함께 고치며,
한 화면에서 입력한 글자가 다른 화면에 나타나기까지의 지연은 중앙값 221ms다.

생성 모델의 지도 학습(SFT)은 더 큰 모델에 적용하기 위한 실험으로, 학습 절차와 데이터를 27B에서 검증하였다. 교내 실문서 학습쌍 4,434쌍으로 학습한 결과
시험 문항의 정답 겹침(chrF)이 27.9에서 36.6으로 오르고, 질문에 없는 숫자가 든 답의 비율이 4.1%에서 0%로 줄었다. 다만 학습쌍이 한 가지 형식뿐이어서
에이전트 단계의 JSON 요청에도 학습한 형식으로 답하는 문제가 드러났으므로, 더 큰 모델에서는 플랫폼의 요청 형식까지 학습 데이터에 넣는다.
AURA가 산출하는 결과는 담당자가 검토해 완성하는 초안이다.

주제어: 온프레미스 LLM, 검색 증강 생성, 지식 그래프, 온톨로지, 문서 작업 에이전트, 행정 문서, HWPX, 공동 편집

# Abstract

University administrative documents, such as government grant announcements, project plans, performance reports, and regulations, contain
personal and internal information and therefore cannot be sent to commercial cloud AI services. As a result, staff have long had to search for,
read, and transcribe past documents by hand. This project implements AURA, a platform that reads, retrieves, drafts, and co-edits these documents
using only on-campus hardware: one operations server without a GPU, two NVIDIA Jetson AGX Thor devices for model serving, and one NVIDIA DGX for
archiving original documents, batch processing, and training.

AURA makes four contributions. First, for document digitization, it reads digital PDFs, scanned documents, photographs, Hangul (HWP and HWPX)
files, and office files while preserving table structure, and it masks personal information using Presidio with eight Korean-specific pattern
recognizers. Second, for GraphRAG, it organizes about 35,000 campus documents into a knowledge graph that links programs, program years, documents,
and sections; the ontology is exported to OWL and validated with SHACL. The generation model, Qwen3.8-27B served with vLLM in NVFP4, interprets
each question in ontology terms, narrows the search scope through the graph, and then combines Kiwi-based lexical search and semantic search with
reciprocal rank fusion (RRF). With this approach, the proportion of section questions whose correct document appeared in the top five rose from
18% with full-text search to 70%. A reranker fine-tuned on campus documents raised R@1 from 0.649 to 0.711 on 12 documents held out from training.
Answers cite only the evidence supplied to the model, and code separately flags any number that does not appear in that evidence. Third, the
document agent selects tools to write and revise sections and fills the content into the original HWPX form while preserving its formatting.
Fourth, in region-level co-editing, people and the agent edit a single document simultaneously in the Hancom web Hangul editor; the median delay
before a character typed on one screen appears on another is 221 ms.

Supervised fine-tuning (SFT) of the generation model was conducted as an experiment in preparation for larger models, and the training procedure
and data were validated on the 27B model. Training on 4,434 pairs built from real campus documents raised the character-level overlap with
reference answers (chrF) on the test set from 27.9 to 36.6 and reduced the proportion of answers containing numbers absent from the question from
4.1% to 0%. However, because all training pairs followed a single format, the model also answered the agent's JSON requests in that format; for
larger models, the platform's request formats will be included in the training data. AURA's output is a draft that staff review and finalize.

Keywords: on-premise LLM, retrieval-augmented generation, knowledge graph, ontology, document agent, administrative documents, HWPX, co-editing
