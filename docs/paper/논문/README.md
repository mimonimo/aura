# 캡스톤 논문 원고

AURA 캡스톤 논문의 장별 원고다. 형식 기준은 [논문 양식 가이드](../논문-양식-가이드.md), 재료는 [논문 원재료](../논문-원재료.md)·
[실험 로그](../실험-로그.md)·[중간 발표자료](../중간-발표자료.md)와 결정 기록(docs/decisions)이다.
전체 분량 목표는 60~70쪽이다.

## 함께 지킬 것

- 서비스 이름은 AURA 로 쓴다. 문체는 「~한다/~이다」, 볼드·이모지·조어 없이 쉬운 말로 쓴다.
- 수치는 저장소 기록(원재료·실험 로그·ADR·progress.json)에 있는 값만 쓰고 장 끝에 출처를 적는다. 재지 않은 것은 「미측정」, 확인하지 못한 것은 「미확인」.
- 캡션은 그림·표 아래에 [그림 n-m]/[표 n-m] 장-일련 번호로 붙인다. 그림이 아직 없으면 「(캡처 필요: 경로/화면)」 또는 「(작성 필요: 도식)」로 자리를 두고 장 끝 표에 모은다.
- 원고 메모(인쇄 전 확인할 점, 쓰는 사람 안내)는 `<!-- -->` 로 감싼다. 논문 문서(웹 기안기)에 옮길 때 빠진다.
- 같은 화면을 여러 장에서 쓰면 처음 나오는 장에서만 번호를 붙이고 뒤에서는 그 번호를 가리킨다.
- 실명은 팀원 확인 전에는 「팀원 n」으로 둔다. 시험 화면은 본문에 「시연 화면」으로 밝힌다.
- 머리글(오른쪽 위)은 줄인 논문 제목, 바닥글은 쪽 번호와 「영남이공대학교 사이버보안과」다. 원고 단계에서는 넣지 않고 편집 단계에서 붙인다.

그림·표 전체 목록과 캡처 상태는 [그림-표-목록.md](그림-표-목록.md)에 모았다(10-24, 장마다 일련번호·캡션 아래·다른 장이 가리키는 그림 포함).
