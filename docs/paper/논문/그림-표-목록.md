# 그림·표 목록

논문 본문(1~5장)과 부록의 그림·표를 장 순서로 모은 표다. 번호는 장마다 일련번호이고 캡션은 그림·표 아래에 둔다. 「자료」 칸은 넣을 파일,
본문 글 상자(코드 블록 그림), 또는 「캡처 필요: 경로」다. 같은 화면을 여러 장에서 쓰면 처음 나온 장의 번호만 두고 뒤에서는 그 번호를 가리킨다
(아래 「다른 장이 가리키는 그림」). 6장에는 그림·표가 없다. 그림 파일은 셋째 칸의 경로에 있다(10-22 첫 촬영 기록은 docs/archive/논문-그림-촬영-기록-1022.md). 플랫폼 화면 그림은 10-27 화면 개편(두 줄 입력창, 사이드바 사용자 메뉴, 개발 화면 세 묶음, 기준 문서 관리의 라이브러리 이동) 뒤 docs/images/figures-1027 로 다시 찍었다.

모든 캡처는 시험 환경(시험 계정, 지어낸 부서·사람·사업, 공통 양식, 공개 공고 서식)이나 운영 화면의 시험 계정으로 찍고 서버 주소·사람 이름·전자우편이 보이지 않게 한다. 구성도 4종은
docs/images/diagrams/ 의 make_diagrams.py(SVG)와 render.mjs(PNG)로 만든다.
