# 그림·표 목록

논문 본문(1~5장)과 부록의 그림·표를 장 순서로 모은 표다. 번호는 장마다 일련번호이고 캡션은 그림·표 아래에 둔다. 「자료」 칸은 넣을 파일,
본문 글 상자(코드 블록 그림), 또는 「캡처 필요: 경로」다. 같은 화면을 여러 장에서 쓰면 처음 나온 장의 번호만 두고 뒤에서는 그 번호를 가리킨다
(아래 「다른 장이 가리키는 그림」). 6장에는 그림·표가 없다. 그림 파일과 촬영 조건은 [그림 목록](../그림-목록.md)에 있다.

모든 캡처는 시험 환경(시험 계정, 지어낸 부서·사람·사업, 공통 양식, 공개 공고 서식)에서 찍고 서버 주소·사람 이름이 보이지 않게 한다. 구성도 4종은
docs/images/diagrams/ 의 make_diagrams.py(SVG)와 render.mjs(PNG)로 만든다.
