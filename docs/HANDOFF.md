  (2026-09-08 OCR 배치에 전체 코어 할당 → VM 6시간 먹통 실사고.)

1. GitHub mimonimo/aura **협업자 권한** 받기 → `git clone`.
2. 학과망 **VPN 접근** + VM SSH 키 등록 (서버를 만질 경우).
3. 새 Claude Code 세션에서 이 문서 + `CLAUDE.md` + `PROJECT_BRIEF.md` 읽고 시작.
