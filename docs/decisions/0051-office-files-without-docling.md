# ADR-0051: 오피스 파일 읽기에서 docling 을 뺀다

- 상태: 채택
- 날짜: 2026-10-06
- 관련: ADR-0050(docling 을 판독 경로에서 뺌 — 3항 「오피스 구조 읽기에만 남긴다」를 대체), ADR-0033(kordoc 읽기 어댑터)

## 맥락

ADR-0050 뒤에도 docx·xlsx·pptx 의 구조 읽기에는 docling 이 남아 있었다. 사용자가 "대조해 보고 나은 걸로 바꿔"라고 했다.
DGX 원본에서 형식마다 24~25건을 무작위로 골라 견줬다(scripts/176, 범위 밖 경로·중복 제외).
정답은 파일 안 XML 에서 직접 모은 글자다(docx w:t · pptx a:t · xlsx 공유 문자열·셀 값, xls 는 LibreOffice 로 xlsx 로 바꾼 뒤 같은 방식).

| 형식 | 방식 | 낱말 재현율 | 정밀도 | 표 개수 맞음 | 표 모양 맞음 | 실패 | 시간(중앙값) |
|---|---|---|---|---|---|---|---|
| docx | docling | 0.874 | 0.883 | 76% | 0.83 | 0 | 0.11초 |
| docx | python-docx | 0.675 | 0.931 | 92% | 0.88 | 0 | 0.00초 |
| docx | kordoc | 0.872 | 0.926 | 92% | 0.84 | 0 | 0.13초 |
| xlsx | docling | 0.952 | 0.964 | 42% | 0.29 | 0 | 0.08초 |
| xlsx | openpyxl | 0.966 | 0.970 | 100%* | 1.00* | 0 | 0.01초 |
| xlsx | kordoc | 0.994 | 0.978 | 100% | 0.96 | 0 | 0.12초 |
| xls | docling(변환 뒤) | 0.994 | 0.961 | 56% | 0.36 | 0 | 1.23초 |
| xls | 변환 → openpyxl | 0.994 | 0.979 | 100%* | 1.00* | 0 | 0.86초 |

\* 엑셀의 표 정답(시트의 쓰인 범위)은 openpyxl 과 같은 방식으로 세므로 표 수치는 openpyxl 에 유리하다. 엑셀은 낱말 수치로 판단했다.

## 결정

1. docx·xlsx 는 kordoc 이 먼저 읽고, 실패하면 python-docx·openpyxl(`ingest/parsers/office.py`).
2. xls·doc·ppt 는 LibreOffice 로 새 형식으로 바꾼 뒤 1·3 을 따른다. kordoc 의 xls 직접 읽기는 25건 중 6건이 실패해서 쓰지 않는다.
3. pptx 는 python-pptx. 쪽마다 도형 글·표·발표자 메모를 읽는다.
4. 처리기(`app/pipeline.py`)에서 docling 을 쓰지 않는다. 오피스 파일에서 글이 빈약할 때 MinerU OCR 로 다시 읽는 경로는 그대로 둔다.

## 결과

- docling 은 처리기에서 빠진다. 패키지·모델 캐시 정리는 운영에서 한동안 회귀가 없는지 본 뒤 따로 한다.
- 다시 견주려면 `scripts/176_office_duel.py --n 25 --seed <새 값>`(DGX) 을 쓴다.
