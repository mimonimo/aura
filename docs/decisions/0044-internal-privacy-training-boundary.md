# ADR-0044: 내부 원문 활용과 학습 반출 보호 분리

상태: 채택 · 날짜: 2026-09-29

사용자 지시로 내부 반입·첨부·응답 마스킹은 기본 꺼짐이다. 개발자 설정에서
전체 켜기·끄기와 항목을 저장하며 이후 처리에 적용한다. 기준 문서 원문 유지
예외는 유지한다. 접근 권한은 변경하지 않고 기존 가림 본문을 자동 복원하지 않는다.

학습 후보는 별도 사본에서 전체 개인정보 탐지를 적용한다. 내부 설정이 학습
보호를 해제하지 않는다. 탐지기 오류는 원문 통과로 처리하지 않는다.
반출과 개별 JSONL 다운로드는 실제 읽은 바이트에 품질 관문과 개인정보 검사를
적용한다. 근거·구조·맥락·개인정보 검수 승인, 근거 일치, 파일 내 사업 단위 분리·
중복 검사를 통과하지 못한 파일은 반출하지 않는다. 여러 파일을 합쳐 학습할 때는
전체 묶음의 사업별 분리·중복을 다시 검사해야 한다.

검사기의 정규식은 라벨 없는 이름·주소 등을 놓칠 수 있다. 자동 통과는 의미
정확성이나 개인정보 완전 제거의 증명이 아니므로 검수자 승인을 함께 요구한다.
기존 Label Studio 주석 완료 건수와 SFT 승인 건수는 구분한다.
RAG 인덱스 반출은 기존 기준 문서 경로이며 학습 데이터 승인을 뜻하지 않는다.

개발 페이지는 설정 상태·현재 후보·과거 처리 기록·실험 기록을 분리한다.
과거 기록 삭제나 원문 일괄 재처리는 이 변경에 포함하지 않는다.
