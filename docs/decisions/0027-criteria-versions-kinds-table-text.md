# 0027. 기준 문서의 판본·서류 갈래·표 평문 규칙 — 반입 때 정한다

- 상태: 채택
- 날짜: 2026-09-22
- 관련: ADR-0016(표 평문·그림 글자·캡션 계약), ADR-0006(기준 문서 마스킹 제외), 브리프 절대 규칙 4·10

## 배경

공개 국고 문서와 교내 게시물 194건을 다시 들인 뒤 세 가지가 눈에 띄었다. 기준 문서 목록에 같은 제목이
줄지어 섰다(「첨단분야 혁신융합대학 사업 가 신청서」 세 건, BRIDGE3.0 양식 두 건). 서식 문서의 본문과
조각 첫머리가 같은 말로 채워졌다(복학원: '예비군대대 | 예비군대대 | 예비군대대 | 복학원 | 복학원 …').
문서가 공고인지 양식인지 계획서인지 구분이 없어 탐색기와 그래프가 연관을 짓지 못했고, 250쪽짜리
글자층 직독 문서의 조각에는 쪽 번호가 없어 원문 이동이 막혔다.

같은 제목의 문서들은 파일 바이트가 다르다. 해마다 공고에 딸린 같은 양식을 조금씩 손봤기 때문이다.
바이트 해시로는 못 잡고, 담당자가 문서마다 손으로 가릴 수도 없다.

## 결정

1. 표 평문은 병합 셀의 글을 한 번만 쓴다. 가로 병합은 첫 칸에만, 세로 병합은 아래 행에 채우되 그 행에
   새 글이 없으면 행을 내지 않는다. 빈 칸은 내지 않는다. 화면 표는 그대로 셀 구조(table_html)로 그린다.
2. 글자층 직독 문서는 쪽별 본문을 유지해 조각마다 쪽 번호를 붙인다.
3. 문서마다 제목을 정규화한 열쇠(family)를 반입 때 적는다. 붙임 번호·괄호·공백·확장자는 제목이 아니다.
   같은 열쇠의 기준 문서가 이미 있으면 본문 겹침을 잰다. 0.95 이상이면 같은 내용으로 보아 받지 않고,
   그보다 낮으면 판본으로 남기되 첫 판본(version_of)에 잇는다. 붙임 번호 앞머리 모양과 사업 이름이 같은
   문서들은 같은 공고에 딸린 묶음으로 보아 머리 문서(공고·계획, 없으면 붙임 1)에 related_criteria_id 로 잇는다.
4. 문서마다 서류 갈래(kind)를 적는다. 공고·양식·계획서·결과보고서·규정·지침·심사기준·안내문·표·현황·증명.
   제목의 낱말이 먼저이고, 없으면 본문 앞머리의 생김새(조문 머리, 결재란, 빈칸 표시, 신청 기간)로 본다.
   확신이 없으면 비워 둔다. 처리 경로를 정하는 doc_type 과는 별개의 축이다.

이 규칙들은 반입 경로(pipeline)와 소급 스크립트(136·137)가 같은 함수(doc_family, doc_routing.guess_kind,
render._row_texts)를 쓴다.

## 근거

- 표 평문 규칙 적용(137): 표 조각 2,743개 중 1,444개의 평문이 바뀌었고 글자 수는 811,240에서 517,902로
  줄었다. 복학원 본문 첫 줄은 '예비군대대 | 복학원 | 결 재 | 담당 | 팀장 | 처장 | 부총장 | 총 장' 이 됐다.
- 판본 판정(136): 같은 제목 묶음 5개, 판본 8건, 같은 내용 0건. 가장 가까운 판본 쌍의 겹침이 0.90(가 신청서
  2022·2023년판, 신청 분야 목록만 다름)이어서 0.95 문턱이 판본을 중복으로 오판하지 않는다.
- 서류 갈래: 문서 192건 중 173건이 갈래를 받았다(공고 23·양식 56·계획서 22·표 21·안내 17·규정 12·지침 7·
  결과보고서 7·심사기준 4·증명 4). 못 정한 19건은 판독이 깨진 스캔과 제목 없는 게시물이다.
- 붙임 잇기: 37건이 머리 문서에 이어졌다(예: 2024년 첨단분야 추진계획 ← 붙임 2~6).

## 되돌리기

문턱값(doc_family.NEAR_DUP, PROGRAM_CHARS)과 갈래 낱말표(doc_routing._KIND_CUES)만 바꾸면 된다.
소급 전 DB 는 `data/platform/platform-<시각>-before136.db`, `-before137.db` 로 남는다.
