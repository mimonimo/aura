# ADR-0054: 지식그래프·온톨로지 시각화는 Cytoscape.js

- 상태: 채택
- 날짜: 2026-10-06
- 관련: ADR-0048(온톨로지 v3), ADR-0009(옛 구조 그래프)

## 맥락

옛 그래프 화면(/graph)은 직접 짠 SVG 배치다. 노드가 많아지면 겹친다. 또 지금 지식그래프(kg_nodes·kg_edges, 노드 42만·관계 59만)가
아니라 요청마다 만드는 옛 문서 그래프를 그린다. 사용자는 노드 연결을 보는 화면의 품질이 낮다고 보고, 오픈소스 시각화를 붙이자고 했다.

## 결정

1. 그리기는 Cytoscape.js(MIT)와 배치 fcose(MIT)로 한다. 파일은 `static/`에 동봉해 외부 접속 없이 돈다(`static/THIRD_PARTY.md`).
2. 화면은 `/graph/explore`이며 두 보기를 둔다.
   - 지식그래프: 노드 하나에서 시작해 두 번 눌러 이웃을 펼친다.
   - 온톨로지: 노드 종류와 (종류→종류, 관계, 기준)별 건수를 그린 구조도다.
3. 그래프 전체를 내려보내지 않는다. 서버는 고른 노드의 이웃만 관계 종류·방향마다 30개씩 잘라 보내고, 「더 보기」로 다음 쪽을 준다.
4. 문서·절·성과지표 노드는 열람 권한(`access_policy.visible`)으로 거른다. 볼 수 없는 문서는 이웃·검색·중심 어디에도 나오지 않는다.
5. 관계를 고르면 기준(구조·분류·식별자 일치·추출·유사도)과 근거 문장을 보인다. 유사도로 추정한 관계는 점선으로 그린다.
6. 저장소는 PostgreSQL 그대로 둔다. 들어오는 관계 조회를 위해 `kg_edges(dst)` 색인을 더한다.

## 결과

- 옛 /graph 와 사업별 표(/graph/program)는 그대로 두고, 탐색은 새 화면에서 한다. 옛 화면을 없앨지는 쓰임을 보고 정한다.
- Memgraph 같은 그래프 DB 는 쓰지 않는다. 보기는 이 화면으로 충분하고, 권한 필터를 같은 DB 에서 거는 구조를 지킨다.
