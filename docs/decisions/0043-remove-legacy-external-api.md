# ADR-0043: 기존 외부 참조 API 기능 제거

상태: 확정 (2026-09-29 사용자 요청)

ADR-0042의 기존 API 경로 비활성화를 대체한다. 사용하지 않는 기능을
차단 상태로 표시하지 않고 화면과 실행 경로에서 제거한다.

- 기존 외부 API 상태·누적 집계 카드, 제출·승인·재전송 경로 제거.
- 채팅의 기존 외부 API 선택 필드와 전송 처리 제거.
- 과거 이그레스 DB 기록은 보존. 기존 GET 주소는 구독 연결 화면으로 이동.
- 웹 검색, 개인정보 검사 유틸리티, 구독 인증 상태 조회는 유지.
- 내부 모델 서버의 연결·호출 기능에는 영향 없음.

구독 로그인 시작·작업 세션 실행은 이 변경에 포함되지 않는다.
최신 사용자 지시로 이번 운영 배포는 Codex가 담당한다.
