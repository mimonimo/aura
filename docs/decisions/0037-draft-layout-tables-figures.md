# ADR-0037 — 초안은 본문만이 아니라 완성본과 같은 구성(양식 표 채우기·표 만들기·도식)으로 낸다

날짜: 2026-09-29 · 상태: 채택 · 관련: ADR-0029(독스 편집 에이전트)·ADR-0035(서식 보존 채우기)

## 배경

사용자 지적(2026-09-29): 작업본을 보면 글만 들어가 있고 표는 깨져 있으며 표 안은 비어 있다. 목표 형태는 문서함의 완성본
「2026년 AID 전환 중점 전문대학 지원사업 사업계획서 Ver.3.3」(2026-국고-0002) — 절마다 본문과 표(세부추진과제 표·총괄표·지표 근거표)
와 도식(정책 동향·산업 수요 같은 요약 인포그래픽)으로 짜여 있다. "근거 자료를 가지고 초안을 생성하되 저런 양식도 에이전트가 만들 줄
알아야 한다. 우선 같은 형식으로 시험하고, 나중에는 여러 문서의 양식을 학습해 초안에 맞는 형식을 고를 수 있어야 한다."

실측: 대화 18 완성본에서 서식 표 채움 0건 — 편집 계획에 '기존 표의 칸에 값 넣기'가 없었고, 표는 작성방법이 요구할 때만 새로 만들었다.

## 결정

1. 양식 표 채우기(`fill`): 절의 양식 표 격자(빈 칸은 `_`, row·col 은 0부터)를 재료에 붙이고, 모델은 `fill`(section, table, cells)로
   빈 칸에 값을 넣는다(`gdocs.fill_table`: 뒤 칸부터, 글이 있는 칸은 바꿈, 표 구조는 그대로). 값 칸이 절반 넘게 빈 양식 표만 있는 절은
   '아직 안 쓴 절'이다(`drafting.is_unfilled`). 한글 완성본(hwpx_fill)은 고쳐 쓴 서식 표를 칸에 써 넣는다.
2. 표 만들기(`table`): 지난 자료(정답지)의 같은 절이 표로 구성돼 있으면 같은 머리 칸의 표를 만들어 이 대학의 값을 넣도록 지시한다.
   에이전트가 넣는 표는 머리 행 음영·굵게. 새 표의 열 너비는 한글 완성본에서 작업본 비율을 따른다.
3. 도식(`figure`): 그림 자리(요약 도식·단계 흐름·추진체계)는 모델이 상자·요점 spec(JSON)을 내고 코드가 카드형·흐름형 PNG 를 그려
   절 끝에 넣는다(`app/infographic.py`). 이미지 생성 모델은 계획(모델 4종)에 없으므로 사진·일러스트는 만들지 않는다. 그림은 프로젝트
   드라이브 `그림/` 폴더에 두고, 독스가 가져오는 동안만 '링크가 있는 누구나' 권한을 열었다가 닫는다(독스 API 는 공개 URL 의 그림만 가져옴).
4. 순서: 먼저 정답지와 같은 형식으로 시험한다(작성서식 작업본 ↔ Ver.3.3). 다음 단계는 문서함 문서들의 절별 표·상자·도식 구성을 자동으로
   모은 '양식 패턴'을 두고 초안 종류에 맞는 구성을 고르게 하는 것이며, 실행 기록(drafting_episodes: 재료·지시·초안·정답)이 그 학습 재료다.

## 한계

- 값은 자료에 있는 것만(브리프 규칙 1). 자료에 없는 칸은 비우고 asks 로 담당자에게 묻는다.
- 도식은 구조 그림이다. 디자이너가 그린 인포그래픽·사진은 재현하지 못한다.
- 그림 공개 링크는 몇 초간 열린다(내용은 요약 도식). 이것도 싫으면 그림을 완성본(hwpx)에만 넣는 길로 바꿀 수 있다.
