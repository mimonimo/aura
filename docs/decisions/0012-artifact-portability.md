# 0012. 학습 산출물 반출성 — 개방 표준 + 매니페스트

- **상태**: 채택
- **날짜**: 2026-09-08
- **관련**: ADR-0011(학습 도구), 데이터 공방, 사용자 요구(2026-09-08)

## 맥락

사용자 요구: 파인튜닝한 모델·전처리 데이터·RAG 인덱스 등 학습 관련 모든
데이터는 추후 반출·타 환경 이식이 가능해야 한다. 다른 곳에 옮겨 쓸 수 있어야
한다. 초기에 형식을 정하지 않으면 장비·벤더 종속으로 묶여 반출이 어려워진다.

## 결정

모든 학습 산출물을 **개방 표준 형식**으로 저장하고, 반출 시 **매니페스트**를
함께 묶는다. 산출물별 형식:

- 파인튜닝 모델: HF 표준(safetensors). LoRA/QLoRA 어댑터 + 베이스 모델 참조
  (베이스는 오픈웨이트라 어댑터만으로 어디서든 재조립). 전체 병합본도 옵션.
- 전처리·학습 데이터: JSONL(sharegpt) — 이미 데이터 공방이 이 형식.
- RAG 인덱스: 재구성 가능한 원천으로. 조각 텍스트 JSONL + 임베딩 npz(numpy
  표준) + 임베딩 모델 id·차원. 어느 환경에서든 같은 모델로 재색인 가능.
- 평가 세트·지표: JSONL + 지표 요약(JSON).

반출 번들(zip) = 위 산출물 + `manifest.json`:
- 생성 시각·플랫폼 버전·git 커밋
- 각 산출물의 종류·형식·파일 목록·행수/크기
- 베이스 모델 id와 라이선스, 임베딩·리랭커 모델 id
- 재현 절차(어떤 스크립트로 재색인·재학습하는지)
- 데이터 민감도 표시(PII 마스킹 여부 — 인풋은 마스킹본만 반출)

## 원칙

- 벤더 고유 포맷 금지. numpy·JSONL·safetensors·JSON만.
- 반출 번들은 그 자체로 자기설명적(매니페스트만 보고 재조립 가능).
- 민감도 게이트: 기준 문서는 원문 반출 가능(공개 성격), 인풋 문서 유래
  데이터는 마스킹본만. 원문·실명이 든 것은 번들에 포함하지 않는다.
- RAG는 벡터(npz)와 원천(조각 JSONL)을 함께 — 벡터만 있으면 다른 임베딩
  모델로 못 옮기므로 원천 텍스트로 재색인 경로를 보장한다.

## 결과와 되돌리기 비용

- 형식을 개방 표준으로 고정 — 도구·장비를 바꿔도 산출물은 그대로 이동.
- 매니페스트 스키마만 계약. 산출물이 늘면 매니페스트에 항목 추가(저비용).
- 되돌리기 비용 없음 — 반출은 읽기 전용 조립이라 기존 데이터에 영향 없음.
