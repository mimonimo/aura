# 0031. 데이터 체계 — 문서 · 지식 · 모델 세 층, 경로는 한 곳

- 상태: 채택
- 날짜: 2026-09-23
- 관련: ADR-0030(문서 저장 구조), ADR-0024(공개 문서 예외), 브리프 절대 규칙 4·6·8

## 배경

사용자 지적: 관리해야 할 자료는 문서(반입·생성·첨부)만이 아니다. 문서를 잘라 만든 조각·색인·지식 그래프(밖으로 내보내
쓸 수 있어야 한다)와, 그것으로 학습한 우리 모델과 학습 자료가 있다. 체계가 확실해야 옮기거나 늘리거나 고치기 쉽다.
지금은 색인·측정·옛 파일럿·캐시가 `data/platform/` 바로 아래에 섞여 있었고, 26개 파일이 제각기 경로를 적고 있었다.

## 결정

1. 세 층으로 나눈다.
   - 1층 문서 `data/platform/documents/` — 반입·첨부·생성·보고(ADR-0030).
   - 2층 지식 `data/platform/knowledge/` — `index/`(조각 임베딩·문서 벡터·질문 색인), `eval/`(검색 품질 측정),
     `exports/`(외부 이용 묶음), `corpus_pilot/`(옛 파일럿, 참고). 원천은 DB 의 조각·개체·간선 표다.
   - 3층 모델 `data/train/` — `datasets/<모델>/<판>/`, `baselines/<모델>/`, `models/<모델>/<판>/`, `runs/<모델>/<판>/`.
     DGX 의 `~/zzaimy/train/` 도 같은 모양이다.
   - 캐시 `data/platform/cache/`(lines·pagecache·restored)는 재생성 가능하며 장부 밖이다. 원본 DB 와 설정·감사 파일은
     `data/platform/` 바로 아래에 둔다.
2. 경로는 `src/zzaimy/app/paths.py` 한 곳에서만 정한다. 뿌리 둘(`ZZAIMY_DATA_DIR`, `ZZAIMY_TRAIN_DIR`)만 바꾸면 전체가
   따라온다. 스크립트도 이 모듈을 쓴다.
3. 지식은 언제든 밖으로 낼 수 있어야 한다. `scripts/140_export_knowledge.py` 가 문서 목록·조각·개체·문서-개체 간선·조각
   임베딩을 jsonl/npz 로 묶고 manifest 에 건수·모델·열람 범위를 적는다. 기본은 전체 공개 문서만이고 부서 제한 자료는
   `--levels` 로 명시할 때만, 담당자 한정 자료는 내보내지 않는다.
4. 학습 자료는 3층에만 둔다. 베이스라인(`baselines/writer/baseline.json`)이 없으면 학습 스크립트가 돌지 않는 규칙은 그대로다.

## 근거

- 합성 검증(`tests/test_paths_layout.py`): 뿌리 변경 추종, 이관, 내보내기(등급 범위·임베딩 필터·zip).
- 운영 이관 결과는 dev-now 에 적는다.

## 되돌리기

`paths.py` 의 기본값을 옛 자리로 바꾸고 139 의 역방향으로 파일을 옮기면 된다. DB 는 바뀌지 않는다.
