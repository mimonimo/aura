# 0064. 반입 자료의 교내 규정을 골라 기준 문서로 올린다

- **상태**: 확정
- **날짜**: 2026-10-13
- **관련**: ADR-0052(학생 학사 규정 말뭉치), ADR-0053(RAG 공간), ADR-0062(라이브러리 한 목록)

## 맥락

DGX 원본으로 들어온 교내 규정·지침은 사업 문서(doc_type grant)로 반입돼 사업 문서 검색에만 쓰였고, 규정 검색(조문 단위 조각·재순위)과
학생 공개 대상(기준 문서, doc_type regulation)은 공고·기본계획 3건뿐이었다. 서류 갈래가 「규정」인 사업 문서는 1,673건이지만
조문 머리(제N조)만 있는 협약서·업체 서류도 섞여 있어 그대로 옮길 수 없었다.

## 결정

- 후보: 처리 완료 사업 문서 가운데 제목이 규정 갈래 이름(규정·규칙·내규·세칙·학칙·정관·지침)으로 끝나고, 협약서·공문·개정안 대비표 같은
  규정을 다루는 다른 서류가 아닌 것. 판본 묶음(family)마다 최신 판 하나 — 옛 판은 사업 문서로 남아 연도를 묻는 질문에 쓰인다.
- 등록: 담당자가 RAG 공간 「규정·기준 문서」에서 골라 올린다. 다시 판독하지 않고 저장된 본문을 반입과 같은 조문 청킹·잡음 관문으로
  조각낸다(app/regulation_register.py). 등록·해제는 data/platform/regulation_register.jsonl 에 남고 해제하면 사업 문서로 돌아간다.
- 새 파일은 라이브러리 「기준 등록」(/criteria/upload)이 그대로 맡는다.

## 결과

2026-10-13 후보 501건(판본 묶음 기준)을 올려 규정 색인 조각 15,454개. 규정 임베딩은 재색인(scripts/66)으로 다시 만든다.
되돌리기: 화면의 「등록 해제」 또는 regulation_register.unregister — 이 모듈이 올린 문서만 되돌린다.
