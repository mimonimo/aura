# ADR-0055: 온톨로지 보강 — 기관 노드와 서류 갈래 확장

- 상태: 채택
- 날짜: 2026-10-06
- 관련: ADR-0048(온톨로지 v3), ADR-0054(그래프 탐색), 절대 규칙 10(하드코딩 금지)·11(지출 문서 범위 밖)·12(관계는 근거가 있을 때만)

## 맥락

그래프 탐색 화면의 온톨로지 보기로 보니, 노드 종류는 7개(사업 묶음·사업·연차·문서·절·단위과제·성과지표)였다. 사업을 누가
주관·관리하는지가 없었다. 문서 갈래는 41,688건 중 15,722건(38%)이 미정이었다. 그래프 생성기(157)의 갈래 이름표에
분류기(doc_routing.KINDS)의 세 갈래(안내문·표·현황·증명·등록증)가 빠져 있어, 화면에 notice·table·certificate 가 영어로 나왔다.

## 결정

1. 기관 노드(org)를 둔다. 사업 → 주관 부처(supervised_by), 사업 → 전담기관(managed_by)으로 잇는다. 값은 외부 확인 장부
   (kg_external.json의 ministry·agency·org_sources·org_confidence·org_checked)에서만 가져온다. 2026-10-06 30개 사업을
   외부 검색으로 확인했다. 주관 부처는 30개, 전담기관은 24개를 확인했다. 근거는 공식 원문 9개, 언론·대학 자료 21개다.
   확인하지 못한 칸은 비워 두고 관계를 만들지 않는다.
2. 서류 갈래에 일반 서류 종류 여섯을 더한다: 증빙·회계 서류, 교육과정·교과, 회의 자료, 홍보물, 도면, 개인 제출물.
   단서는 서류 종류에 붙는 일반 낱말(견적서·거래명세서·회의록·리플렛·평면도·수기 등)이다. 특정 문서에 맞춘 규칙이 아니다.
3. 그래프의 갈래 이름은 분류기 KINDS 하나를 따른다. 사업 문서에서 쓰는 말(실적보고서·평가 결과·평가 기준)만 덮어쓴다.

## 결과

- 갈래 미정 15,722건 중 3,391건이 제목만으로 새 갈래에 들어간다. 그래프를 다시 지을 때는 본문 앞머리도 본다.
- 증빙·회계 서류로 알아본 문서는 그래프 전체에서 2,335건이다. 지출 문서 계열(규칙 11)인데 폴더 이름 필터를 빠져나와
  RAG·그래프에 들어가 있었다. 검색·그래프에서 뺄지는 사용자 판단으로 남긴다(통장 사본 등 개인정보도 섞여 있다).
