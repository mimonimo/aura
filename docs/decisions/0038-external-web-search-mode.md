# ADR-0038 — 외부 검색 모드: 문서 작업이 아닌 일반 질문은 27B 가 웹 검색 결과로 답한다

날짜: 2026-09-29 · 상태: 채택 · 관련: ADR-0029(채팅 에이전트), 유출 통제(ADR-0033 5항)

## 배경

사용자 실측(2026-09-29): "AI 가속기 B200 과 H200 의 차이" 를 물으니 행정 에이전트가 "등록된 기준 문서에서 근거를 찾지 못했다" 고만 답했다.
문서·규정 질문이 아닌 일반 지식 질문에는 외부 검색이 필요하다. 제안: 켜고 끄는 모드로 두고, 27B 의 능력으로 외부 검색을 하게 한다.

## 결정

1. 채팅 '외부 참조' 판에 "외부 검색 모드 (웹)" 토글을 둔다(`web` 폼 값). 켠 메시지만 이 길로 간다.
2. 흐름(`app/web_search.py`): 질문 글로 DuckDuckGo HTML 검색 → 상위 쪽 몇 개의 글만 추출(스크립트·메뉴 제거) → 교내 Writer 27B 가
   그 자료만 근거로 답하고 문장마다 [n] 출처 번호를 단다 → 화면에 답 + 출처 목록. 자료에 없는 것은 모른다고 쓴다(브리프 규칙 1).
3. 유출 통제: 밖으로 나가는 것은 담당자가 친 질문 글뿐이다. 문서·첨부·교내 조각·기관 정보는 보내지 않는다. 외부 모델 참조(egress,
   토큰화)와는 다른 길이며 외부 모델을 쓰지 않는다(모델은 계획한 4종 그대로).
4. 실측(2026-09-29, VM): 위 질문에 3개 출처로 연산 성능·전력·연결성 비교를 출처 번호와 함께 답했다.

## 한계·다음

- 검색 엔진은 키 없는 DuckDuckGo HTML 이라 차단·형식 변경에 약하다. 바뀌면 `web_search.search` 의 파서만 고친다.
- 질문에 개인정보·기관 내부 정보가 섞여 있으면 그대로 나간다 — 토글의 안내문에 적었다. 필요하면 egress 의 토큰화를 이 길에도 붙인다.
- 토글 자리는 화면 담당(아스트라)이 + 메뉴로 옮길 수 있다.
