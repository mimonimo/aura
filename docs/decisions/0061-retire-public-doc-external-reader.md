# 0061. 공개 자료 외부 판독 경로 폐기

- 상태: 확정
- 날짜: 2026-10-12
- 관련: ADR-0024(대체됨), ADR-0043(기존 외부 참조 API 기능 제거)의 확장, ADR-0017(LLM 연결 관리), 브리프 절대 규칙 3·9

## 배경

ADR-0024는 공개 수집 문서에 한해 상용 API(Anthropic)로 판독하는 길을 열었다. 연결 종류 `anthropic`, 용도
`vision_public`, 반입에서 공개 수집 문서를 그 용도로 돌리는 분기가 그 결정의 구현이다.

그 뒤 공개 수집 코퍼스는 운영 범위에서 빠졌다. 절대 규칙 9는 계획서의 모델 4종만 쓰게 한다. 운영 VM의 연결
설정에는 상용 API 연결이 없고, 키 등록과 비용 실측도 이뤄지지 않았다. ADR-0043은 다른 외부 API 기능을 이미
걷어 냈다.

## 결정

공개 자료 외부 판독 경로를 코드와 화면에서 없앤다. ADR-0024는 대체됨으로 둔다.

- 연결 종류 `anthropic`, 용도 `vision_public`, 반입의 공개 문서 판독 분기, 클라이언트의 상용 API 비전 처리, 모델
  화면의 「공개 자료 판독」 단계를 제거한다. 판독은 문서 출처와 관계없이 `vision` 용도(Writer 27B) 하나다.
- 외부 서버 연결은 어떤 용도에도 직접 지정할 수 없다. 단건 저장과 일괄 저장이 같은 검사를 거친다.
- 옛 설정 파일에 없는 종류의 연결이나 없는 용도가 남아 있으면 읽을 때 빼고 경고를 한 번 남긴다. 그 연결을
  가리키던 기본 연결·용도 지정도 비운다. 다음 저장 때 파일에서도 빠진다.
- 교내 vLLM 연결, 용도별 지정, 장애 넘김은 그대로다.

외부 기관 GPU 서버(`partner`)는 남긴다. 상용 API가 아니라 ADR-0017의 기관 서버이고, 문서 작업 기본 연결을
개인정보 검토 확인 뒤 지정하는 경로와 연결 진단 안내가 아직 이 종류를 쓴다. 이 종류의 폐기는 ADR-0017을
다시 정할 때 따로 판단한다.

## 결과

- 상용 API로 문서가 나가는 경로가 코드에 남지 않는다.
- 공개 문서도 교내 판독 모델로 읽는다. 품질 비교가 필요하면 계획 모델 안에서 대결 수치로 정한다.
- `scripts/134_render_pages.py` 는 사람이 원본과 판독 결과를 대조하기 위한 쪽 그림 추출로만 쓴다.
