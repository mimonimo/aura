# 결정 기록 (ADR)

구조·기술 선택과 변경 근거를 기록한다. 각 문서는 결정 내용·상태·날짜를 포함한다.

## 언제 쓰는가

- 브리프·리서치가 선택지만 남긴 지점을 확정할 때 (예: Qdrant vs pgvector)
- 실증 결과가 리서치의 추천을 뒤집을 때 (예: bake-off에서 Docling 승)
- 구현 범위를 변경할 때
- 하이퍼파라미터·데이터 규모 등 학습 관련 결정 전부

## 규칙

- 파일명 `NNNN-짧은-제목.md`, 번호는 증가만 한다
- **기존 기록을 고쳐 쓰지 않는다.** 결정이 바뀌면 새 번호로 쓰고 옛 것을 `대체됨`으로 표시
- 승인 전 결정은 `제안`으로 표시한다
