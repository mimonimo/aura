# ADR-0022 임베딩 베이스 KURE-v2 · MinerU vlm 백엔드 — 둘 다 보류

상태: 제안 (교수님 판단 필요한 것은 KURE-v2 항목) · 날짜: 2026-09-21

## 배경

사용자가 두 가지를 물었다. "KURE 도 v2 를 쓰면 되지 않나", "MinerU 도 토르로 옮겨 OCR 을 강화할 수 있지 않나".
둘 다 같은 날 실측했다.

## KURE-v2

공개된 `nlpai-lab/KURE-v2` 를 토르 03 에 받아 구조를 봤다. 단일 벡터 모델이 아니다 —
PyLate(ColBERT 계열) 다중 벡터 모델이다(`modules.json` 의 `pylate.models.Dense.Dense`, 297MB).
지금 검색은 조각당 벡터 하나를 코사인으로 견주고(색인 npz, 서비스 :8016), 질의 임베딩도 같은 방식이다.
KURE-v2 를 쓰려면 색인 형식·임베딩 서비스·점수 계산(MaxSim)을 통째로 바꿔야 한다.
계획 문서(model-plan §1)의 ①베이스는 KURE-v1 단일 벡터다.

결정(제안): **보류.** 베이스 교체가 아니라 검색 구조 변경이므로 별도 결정이 필요하다.
바꾼다면 조건 — 같은 질의 세트에서 후보 진입률(R@20)·R@1 을 지금 운영(zzaimy-embed-v2)과 나란히 재고,
다중 벡터 색인의 크기·질의 시간을 함께 적는다. 그 전까지 KURE-v1 학습판(v2)을 유지한다.

## MinerU vlm 백엔드(토르 GPU)

MinerU 3.4.5 의 `vlm-http-client` 로 토르 03 의 vLLM(젯슨 빌드)에 `MinerU2.5-2509-1.2B` 를 올려 문서 310
두 쪽을 넣었다. 25~33초로 빠르지만 결과가 잡음이다(`《目录》之《礼》…`, `[2022] 2022.05.05 26:50` 반복).
그림은 들어간다(입력 1,471토큰). MinerU 의 로짓 처리기(`mineru_vl_utils:MinerULogitsProcessor`)를
붙여도, `-l korean` 을 줘도 같다. 젯슨 vLLM 빌드와 이 모델의 궁합 문제로 본다(x86 의 MinerU 전용 서버
명령이 젯슨엔 없다).

결정: **보류.** PDF 구조 추출은 MinerU 파이프라인(VM CPU, korean)으로 두고 스캔·깨진 글자층은 27B 판독으로
간다. 다시 시도한다면 MinerU 가 지정한 vLLM 판을 젯슨용으로 맞추는 일부터다.

## 덧붙임(2026-09-21 15:40) — 27B 양자화 판은 이 젯슨 vLLM 빌드(0.19.0)에서 못 쓴다

- `nvidia/Qwen3.8-27B-NVFP4`: 양자화된 lm_head 를 모델 클래스가 못 받아 적재 실패.
- `Qwen/Qwen3.8-27B-FP8`: 가중치는 읽히나 torch.compile 직후 KV 캐시 시험 실행에서 `CUBLAS_STATUS_EXECUTION_FAILED`.
  페이지 캐시를 비워 CUDA 가용 102GB 를 확보해도, `--enforce-eager` 로도 같다. GPU 자체는 정상(bf16 GEMM 시험 통과).

결정: **토르 02·03 모두 bf16 원본으로 통일**(검증된 판). 요청당 속도(~5 토큰/초)는 두 대 분담으로
대화와 배치를 분리해 감당하고, 양자화는 vLLM 새 빌드가 젯슨에 나올 때 다시 본다. DGX → 토르 이관도
bf16(어댑터 또는 병합본)으로만 한다.


## 덧붙임 2(2026-09-21 16시) — FP4 는 소프트웨어 문제, 전용 빌드로 다시 본다

젯슨 토르는 FP8·FP4 를 하드웨어로 가속한다(5세대 텐서 코어). 실패는 vLLM 0.19 의 Qwen3.8 클래스가 양자화된
lm_head 를 못 받는 것이었다. NVIDIA 젯슨 vLLM 이미지에 `qwen3.8-next-jetson-thor` 태그(Qwen3.8 전용 빌드)가 있어
그 빌드로 NVFP4 적재를 다시 시험한다. 되면 채택 조건은 같다 — bf16 과 같은 입력으로 검토·판독 대결과 초안의
수치 대조. 우선순위: NVFP4(요청당 ~4배) → FP8(~2배) → bf16(바닥).
학습본 이관: DGX 에서 bf16 학습·병합 → (채택된 판으로 양자화, ModelOpt) → 토르 두 대. 116 이 그 통로다.
