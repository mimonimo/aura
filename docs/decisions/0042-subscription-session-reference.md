# ADR-0042: 외부 참조 AI는 구독 로그인 작업 세션으로

상태: 사용자 방향 확정, 구현 진행 (2026-09-29)

사용자는 API 키 호출을 사용하지 않고 플랫폼에서 Claude·아스트라(Codex)를
로그인한 뒤 작업 세션을 열어 관리하기를 요청했다. DuckDuckGo 웹 검색과 다른 기능이다.

## 결정

- 기존 외부 참조 API 전송을 비활성화한다. 환경변수/기존 API 키로 자동 재활성화하지 않는다.
- 개인정보 점검과 외부 연결 관리의 진입점을 통합한다. 이전 `/dev/egress` GET은 새 화면으로 이동한다.
- 구독 로그인 확인과 작업 실행 준비 상태를 구분한다. CLI가 있다는 것만으로 로그인/실행 가능으로 표시하지 않는다.
- 인증 정보·CLI 원 출력·이메일을 상태 DB에 저장하지 않는다. 상태 확인 시 API 인증 환경변수를 전달하지 않는다.
- 로컬 인증도 원격 서비스로 내용을 전송할 수 있다. 문서 권한·명시적 전송 승인·개인정보 보호가 별도로 필요하다.
- 임의 셸 명령 실행, 구독 인증 우회, 기존 개발 세션 탈취/공유는 구현하지 않는다.

## 현재 구현과 남은 일

현재는 고정 명령 `claude auth status --json`, `codex login status`의 상태만 조회한다.
플랫폼의 로그인 시작, 사용자별 자격 증명 격리, 작업별 안전한 디렉터리, 생성/재개/중지,
출력 제한 및 외부 전송 승인 연결은 미완료다. 관리자 공용 로그인으로 일반 사용자가
임의 문서에 접근하는 구조로 확장하면 안 된다. 배포는 Claude 담당.

Codex 공식 인증·앱 서버 문서와 설치된 CLI 도움말을 확인했다:
- https://learn.chatgpt.com/docs/auth
- https://learn.chatgpt.com/docs/app-server

기존 ADR-0008의 개인정보 전송 보호 취지는 유지하며, 외부 API 전송 구현 경로만 대체한다.
