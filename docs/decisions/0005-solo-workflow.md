# 0005. 단독 워크플로 전환 — PR 절차 생략

- 상태: 확정 (사용자 결정, 2026-09-01)
- 날짜: 2026-09-01
- 관련: `docs/workflow.md`, `docs/instructions/W1-W2.md` 작업 방식

## 맥락

원 작업 지시서는 "한 태스크 = 한 브랜치 = 한 PR + 교수님 승인"을 전제했다.
2026-09-01 사용자가 역할을 확정했다: 교수님은 초기 개념 제시까지이며,
구축·시운영·의사결정은 사용자(학생) 단독 수행. PR 승인 절차의 승인자가
실질적으로 없으므로 절차를 조정한다.

## 결정

- 브랜치 규율은 유지한다: 한 태스크 = 한 브랜치, 검증(테스트·린트) 통과 후 병합.
- PR 단계는 생략하고 병합 후 `origin/main`에 직접 푸시한다.
- P1 설계 문서 5종도 이 규칙으로 main에 병합했다 (2026-09-01).
- 교수님 공유가 필요한 결정은 ADR·GitHub 링크로 전달한다. 검토 의견이 오면
  후속 커밋으로 반영한다.

## 결과와 되돌리기 비용

승인 관문이 없어지므로 검증 규율(테스트 통과 없이는 병합 금지)이 유일한
품질 게이트가 된다. 협업 인원이 늘면 PR 절차를 되살린다 — 비용은 설정 변경뿐.
