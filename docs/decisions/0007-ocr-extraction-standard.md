# 0007. 문서 추출(OCR) 표준 파이프라인 — 실데이터에 그대로 적용

- 상태: 확정 (사용자 지시: "지금 품질을 끌어올리면 그대로 쭉 가야 한다")
- 날짜: 2026-09-02
- 관련: `src/zzaimy/app/pipeline.py`, `src/zzaimy/app/render.py`, ADR-0004(서빙)

## 맥락

실물 테스트(상장 사진, 손글씨 노트, 스캔 문제집 12쪽, 논문 포스터, 편성표 PDF)로
추출 품질을 끌어올렸다. 이 구성이 향후 실데이터(국고사업·채용·입학 서류) OCR의
기준 파이프라인이다.

## 결정 — 입력별 처리 경로

| 입력 | 경로 | 근거 |
|---|---|---|
| 사진(JPG·PNG) | Qwen3.5 비전 판독 (실패 시 MinerU) | 손글씨·도장 문구까지 판독. PaddleOCR이 깨뜨린 손글씨 표를 정확 복원(실측) |
| PDF 4쪽 이하 | 쪽별 렌더(pypdfium2) → 비전 판독 | 오인식 최소화, 볼드·머리글 보존 |
| PDF 5쪽 이상 (디지털) | MinerU(`auto`) 구조 추출 + **원본 텍스트 레이어 오버레이** | 구조(표·2단·좌표)는 MinerU, 글자는 원본 레이어에서 bbox 사각형으로 추출해 그대로 교체 — OCR 오인식 원천 차단("기초과학→기추과하" 실사고 대응). MinerU `txt` 모드는 이 문서에서 태스크 실패(RuntimeError)해 채택 안 함 |
| 디지털 PDF 복원 뷰(원본 배치) | **글자 좌표 직독**(`pdf_lines.py`, pdfium charbox) | 검색·DB용 조각과 별개로, 화면 복원은 글자 하나하나의 실제 좌표·색·굵기를 읽어 줄 단위로 재구성 — 잘림·중복·위치 오차가 원리적으로 없음. 조각 병합은 하지 않고(2단 목차 보호), 글꼴 폭 차이는 글자 간격으로 자기 박스 폭만 채워 흡수 |
| 복원 뷰 공통 구조 (2026-09-02 확정) | **원본 렌더 배경 + 투명 텍스트 레이어** | "원본 디자인은 그대로, 그 위에 OCR"(구글 OCR PDF 원리). 디지털 PDF=좌표 직독, 스캔 PDF=MinerU middle.json 줄 좌표(신뢰도≥0.5), 사진=보정 스캔 배경+OCR 줄 좌표(내용 판독은 비전 모델). 세 입력이 같은 계약(layout_pages+page_image_url)으로 합류. 검색 가능 PDF 내보내기도 동일 줄 좌표 사용 |
| PDF 5쪽 이상 (스캔) | MinerU(`-m auto`) → OCR + AI 오타 교정 | 표 구조·2단 레이아웃·읽기 순서 보존. 실패 시 docling 폴백 |
| HWP/HWPX·텍스트 | 전용 파서 | 원문 텍스트 확보 |

공통 규칙:
- 비전 전사 형식: 제목 `## `, 강조 `**굵게**`, 표는 HTML `<table>`(rowspan/colspan·th)
  — 병합 셀과 머리글 음영을 구조로 보존한다
- 그림: 본문 읽기 순서 제자리에 배치, 120px 미만 아이콘·중복은 제외, 문서당 20장 상한
- 직인(도장): OpenCV 색 분리로 별도 크롭 저장
- 저장 계약: `doc_chunks`(heading/text/table(JSON 구조)/image, page_no 순서)
  + `doc_assets`(그림 파일 경로). 렌더링·CSV/MD 내보내기·후속 검색이 전부 이 계약을 읽는다
- 인풋·추출 문서는 조각 단위 PII 마스킹, 원본 파일은 장비 안에만

## 남은 한계 (다음 고도화 대상)

- 텍스트 레이어 오버레이는 문단·제목만 교체 — 표 셀은 셀 단위 bbox가 없어 v1에서는
  MinerU 인식 결과 유지 (다음 고도화: 셀 사각형 추정 후 셀 텍스트도 원문 교체)
- 셀 배경색·열 비율 등 시각 서식은 구조(머리글 th)로 근사 — 원본 색상 자체는 미보존
- 5쪽 초과 스캔 PDF는 MinerU 품질에 의존 — 필요 시 쪽 범위 지정 비전 판독 추가 예정
- 흘린 손글씨는 비전 모델도 오독 가능 — "(판독 불가)" 표기를 지시해 지어내기 방지

## 결과

플랫폼 접수 경로(검토·기준 등록)도 동일 파서 스택을 쓰므로, 이 표준의 개선이
실데이터 처리 품질로 직결된다. 회귀는 테스트(구조 조각·표 JSON·내보내기)로 방지한다.
