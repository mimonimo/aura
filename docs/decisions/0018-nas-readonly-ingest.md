# 0018. 교내 NAS 연동 — 읽기 전용 계정으로 가져오기(pull)만, 기준 문서·문서 추출 자동 반입

- 상태: 확정
- 날짜: 2026-09-17
- 관련: ADR-0006(기준 문서 마스킹 제외), ADR-0007(문서 추출 파이프라인), 브리프 절대 규칙 3(인덱싱 전 PII 마스킹)

## 배경

지금은 기준 문서와 문서 추출을 담당자가 손으로 올린다. 학교 NAS 에 규정·공고·서식이 이미 모여 있으므로,
읽기 전용 계정으로 NAS 의 폴더를 주기적으로 읽어 같은 처리 경로(저장 → 파싱·OCR → 마스킹 → 색인)로 넣으면
수집이 자동화된다. NAS 쪽에 흔적을 남기거나 파일을 바꾸는 일은 없어야 한다.

## 결정

1. 연동 모듈 `src/zzaimy/ingest/nas_sync.py`. 백엔드는 두 가지: 서버 경로(관리자가 마운트한 공유나 사본)와
   SMB 공유(`smbprotocol`, 순수 파이썬, 오프라인 휠 `scripts/80_install_smb.sh`). 두 백엔드 모두 목록·열기·읽기 API 만
   쓰고 쓰기·삭제 API 는 호출하지 않는다.
2. 원천 정의(`data/platform/nas_sources.json`, 0600)에 이름·방식·경로·읽기 전용 계정·반입 대상(기준 문서 + 업무 영역,
   또는 문서 추출)·확장자·하위 폴더 포함·자동 반입 간격을 둔다. 비밀번호는 파일에만 있고 화면에는 유무만 보인다.
3. 반입 규칙: 확장자 필터 통과 파일만. 같은 경로에 크기·수정 시각이 같으면 건너뛴다. 내용 해시(sha1)가 이미 반입된
   문서와 같으면 이름이 달라도 중복으로 기록만 남긴다. 새 파일은 로컬 inbox 에 복사한 뒤 `db.add_document` → 
   `processor.process` 로 수동 업로드와 같은 경로를 탄다(마스킹 규칙 동일). 처리 실패는 문서 상태에 남기고 반입은 계속한다.
4. 실행: 화면에서 "지금 반입"(백그라운드 스레드, 진행률 표시) 또는 자동 반입(켜진 원천만, 간격 경과 시, 한 번에 하나).
   결과는 항목별(반입·중복·실패)로 화면에 남긴다.
5. 개발자 전용 화면 `/dev/nas`. 허브 운영 도구 카드 "NAS 수집".

## 결과

- 담당자의 수동 업로드는 그대로 두고, 폴더 단위 자동 반입이 추가된다.
- NAS 계정은 읽기 전용으로 발급받아 등록한다. 서버 경로 방식은 관리자가 마운트해 주면 패키지 없이 바로 쓴다.
