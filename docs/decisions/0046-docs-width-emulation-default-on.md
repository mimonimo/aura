# ADR-0046: 독스 변환의 장평 흉내를 기본으로 켠다

상태: 채택 · 날짜: 2026-09-30

## 배경

한글은 글자 폭을 줄이는 장평(95%·90% 등)을 흔히 쓰고, 독스에는 글자 폭을 조절하는 수단이 없다. 그래서 독스 변환본은 줄이 더 많이
넘어가 쪽이 늘어난다(ADR-0036·0045 의 남은 원인). 변환기에는 장평을 흉내 내는 설정(ZZAIMY_DOCS_WIDTH_EMULATE — 장평만큼 글자 크기를
줄이고 줄 간격 배수를 올려 줄 간격은 원본 그대로)이 있었으나 꺼져 있었다.

## 측정 (scripts/154 경로 A, Nanum Gothic, 2026-09-30)

| 문서(원본 쪽) | 끔 | 켬 |
|---|---|---|
| 사업계획서(73) | 95 | 91 |
| 작성서식(62) | 58 | 58 |
| 평가편람(22) | 22 | 22 |

글자 덮기는 같다(97.0·95.9·100%). 켠 사업계획서 20쪽을 눈으로 보았고 표 칸 글이 겹치거나 잘리지 않았다.

## 결정

독스 규칙(line_rule=docs)일 때 기본으로 켠다. LibreOffice 열람 PDF(exact 규칙)에는 적용되지 않는다. ZZAIMY_DOCS_WIDTH_EMULATE=0 으로 끌 수 있다.

## 남은 것

사업계획서는 원본보다 18쪽 많다. 남은 후보는 표 안 줄 넘김(칸 여백·글꼴 폭 차이)과 그림 배치다(미확인).
