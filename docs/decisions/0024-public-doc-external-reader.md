# 0024. 공개 수집 문서의 판독에 한해 상용 API를 허용한다 (ADR-0017의 예외)

- 상태: 제안 (사용자 제안 2026-09-21. 공개된 자료는 클로드 같은 모델로 품질을 올릴 수 있지 않은가)
- 날짜: 2026-09-21
- 관련: ADR-0017(상용 클라우드 API 불사용), ADR-0008(외부 참조 관문)

## 배경

국고 공고나 외부 안내처럼 이미 공개된 문서에는 개인정보와 교내 정보가 없다. 스캔 매뉴얼 같은
문서의 판독 품질은 모델의 힘에 크게 좌우된다. 계획 밖 소형 모델은 없는 문장을 지어냈고 27B는
정확했다. 상용 모델의 판독은 그보다 강하고 빠르다.

## 결정

연결 종류에 상용 API(OpenAI 호환 주소)를 두되, 외부 연결은 공개 자료 판독 용도에만 지정할 수 있다.
문서 작업, 반입 검토, 일반 판독에 지정하려 하면 코드가 거부한다. 반입은 문서가 공개 수집분일 때만
그 연결을 쓰고, 교내 문서와 사용자 문서는 어떤 경우에도 밖으로 나가지 않는다. 키는 화면에서 넣는다.
개인 구독은 사람이 쓰는 것이라 자동 반입에는 API 키가 필요하다.

ADR-0017의 상용 API 불사용 원칙은 교내 문서와 사용자 문서에 대해 그대로 유효하다. 이 결정은 그
범위 밖인 공개 자료의 예외다.

## 미정

실제 키 등록과 비용 실측은 아직이다. 쪽당 이미지 1,500토큰 안팎이라 36쪽 문서에 수백 원이 들 것으로
본다. 교수님 판단 뒤 켠다.
