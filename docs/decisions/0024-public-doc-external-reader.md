# 0024. 공개 수집 문서의 판독에 한해 상용 API(클로드) 허용 — 0017 의 예외

- 상태: 제안 (사용자 제안 2026-09-21: "공개된 자료는 클로드 같은 모델로 품질을 올릴 수 있지 않나")
- 날짜: 2026-09-21
- 관련: 0017(상용 클라우드 API 불사용) · 0008(이그레스 게이트웨이)

## 배경

국고 공고·외부 안내처럼 이미 공개된 문서는 개인정보·교내 정보가 없다. 스캔 매뉴얼 같은 문서의 판독 품질은
모델 힘에 크게 좌우되고(gemma4 는 없는 문장을 지어냈고 27B 는 정확했다), 상용 모델의 판독은 더 강하고 빠르다.

## 결정(제안)

- 연결 종류 `anthropic`(OpenAI 호환 주소)을 두되, 외부 연결은 **`공개 자료 판독(vision_public)` 용도에만** 지정된다.
  문서 작업·반입 검토·일반 판독에 지정하려 하면 코드가 거부한다.
- 반입은 문서가 공개 수집분(owner=corpus)일 때만 그 연결을 쓴다. 교내·사용자 문서는 어떤 경우에도 밖으로 나가지 않는다.
- 키는 화면에서 넣는다. 구독(claude.ai·Claude Code)은 사람이 쓰는 것이라 자동 반입에는 API 키가 필요하다.
- 0017 의 "상용 클라우드 API 불사용"은 교내·사용자 문서에 대해 그대로 유효하다. 이 결정은 그 범위 밖(공개 자료)의 예외다.

## 미정

- 실제 키 등록·비용 실측(쪽당 이미지 1.5천 토큰 안팎, 36쪽 문서 수백 원 예상)은 아직이다. 교수님 판단 뒤 켠다.
