# 0052 — SFT 데이터 두 묶음

상태: 채택 · 2026-10-06

## 범위

- 규정·발전계획: 지정된 규정집 2개, 지침집, 중장기 연구보고서, VISION2030.
  적용 조건·예외·계획 연계를 근거 발췌와 짧은 판단 설명으로 학습한다.
- 사업 구조·검색 활용: 기존 반입 자료에서 사업·연차·문서 유형·목차 관계를 이해하고,
  RAG·지식그래프 조회 대상을 선택하는 연결 대화를 만든다.
  내부 예산·실적·평가 사실과 원문은 학습 대화에 복사하지 않는다.

외부 웹 자료 수집은 하지 않는다. 가상 사업 자료를 새로 만들지 않는다.
사업 자료의 사실·수치는 사용자 권한을 적용한 RAG·지식그래프에서 조회한다.
규정·발전계획도 버전과 적용 대상을 보존한다.

## 관리

두 묶음은 data/training/tracks 아래 별도 명세·원문 해시·후보·검수 이력으로 관리한다.
이전 CoT는 백업 후 활성 경로와 Label Studio에서 제거한다. 재사용은 새 기준 검수 후에만 허용한다.
생성 후보는 승인본이 아니며, 이전 대화·짧은 근거 설명을 포함한다.
현재 검색 활용 후보는 검색 계획 학습이다. 실제 도구 실행 기록과 동일하지 않으며
운영 검색 도구 재현·권한 검사 및 평가를 통과하기 전 도구 실행 학습 완료로 표시하지 않는다.
SFT 실행은 별도 검수·평가셋 분리·베이스라인 후 수행한다.
