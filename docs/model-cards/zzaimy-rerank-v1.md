# 모델 카드: ZZAIMY-Rerank v1

- 역할: 하이브리드 검색 후보(상위 10개)를 질의 연관도로 재정렬한다. 모델 4종 가운데 둘째.
- 베이스: `BAAI/bge-reranker-v2-m3` (교차인코더, 약 568M)
- 학습: 2026-09-20, 젯슨 AGX 토르 03 (통합 메모리 122GB, 2에폭 21분)
- 산출물: 서빙 장비의 `~/zzaimy/models/zzaimy-rerank-v1` (서비스 포트 8015)
- 재현: `bash scripts/104_train_rerank_on_thor.sh 2` → 검증 `scripts/106_rerank_holdout_check.py`

## 학습 데이터

운영 하이브리드 검색이 실제로 올린 상위 10개 후보를 쓴다. 그 안의 정답이 양성, 나머지가 음성이다.
무작위 음성은 너무 쉬워서, 검색이 실제로 헷갈리는 후보로 배우게 했다.

- 질의: 합성 질의 세트(`data/interim/synth_queries.jsonl`)에서 만든 1,454건 가운데 학습 1,227건.
  상황형으로 바꿔 쓴 질의(`synth_queries_paraphrase.jsonl`)는 학습에 쓰지 않고 평가에만 썼다.
- 문서 단위 홀드아웃: 60문서 중 12문서(고정 시드 20260920). 같은 문서의 질의가 학습·평가에
  함께 들어가지 않는다.
- 조각 본문은 `문서이름 표제\n본문 900자`, 쌍 길이 512토큰으로 운영 호출과 같게 맞췄다.
- 개인정보: 적재 단계에서 마스킹된 조각만 썼다. 학습 자료는 따로 보관하지 않는다.

## 학습 방법

질의마다 후보 목록 전체에 소프트맥스를 걸고, 정답이 그 안에서 1위가 되도록 교차엔트로피를
줄인다(목록 단위). AdamW lr 8e-6, OneCycle(warmup 10%), 그래디언트 클립 1.0, bf16 autocast.
에폭 1 평균 손실 0.955 → 에폭 2 0.675.

## 평가 (학습에 쓰지 않은 문서만)

운영 경로(어휘+조밀 하이브리드 → 리랭커)에서 같은 후보를 베이스와 학습본이 각각 매기게 해 비교했다.

| 홀드아웃 질의 | 방식 | R@1 | R@5 | MRR@10 |
|---|---|---|---|---|
| 정확한 질문 114건 | 하이브리드 | 0.544 | 0.860 | 0.678 |
| 정확한 질문 114건 | 베이스 | 0.649 | 0.903 | 0.751 |
| 정확한 질문 114건 | 학습본 | 0.711 | 0.903 | 0.790 |
| 상황 질문 14건 | 하이브리드 | 0.357 | 0.786 | 0.512 |
| 상황 질문 14건 | 베이스 | 0.429 | 0.786 | 0.559 |
| 상황 질문 14건 | 학습본 | 0.500 | 0.786 | 0.631 |

속도: 질의당 0.07초(후보 10개, 512토큰, GPU). 모델 크기가 같아 베이스와 같다.

## 한계와 주의

- 상황 질문 홀드아웃은 14건뿐이다. 그 줄의 개선폭(+0.071)은 질의 한 건만큼의 차이라 참고치로만 읽는다.
- 학습 질의는 사람이 쓴 질문이 아니라 합성 질의다. 교내 실문서와 실제 질의가 쌓이면 다시 학습한다.
- 점수 눈금이 베이스와 다르다(정답 중앙값 1.000, 무관 질의 최댓값 0.000). 근거 하한은 0.005이며, 모델을 바꿀
  때마다 `scripts/105_rerank_floor.py`로 다시 잰다.
- R@5·R@10은 베이스와 같다. 리랭커는 후보 안의 순서만 바꾸므로 후보에 없는 정답은 살릴 수 없다. 그 부분은
  검색(Embed와 어휘 검색)의 몫이다.
- 지식을 넣은 것이 아니라 순위 판단 능력을 맞춘 것이다(절대 규칙 8). 조각 본문이 학습에 들어가지만, 답변을
  생성하는 모델이 아니므로 수치를 지어내는 통로가 되지 않는다.
