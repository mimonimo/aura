학습 순서

  1. 데이터 공방에서 학습 쌍 생성 → Label Studio에서 사람 검수·정답 확정
  2. 베이스라인 측정 — 학습 전 성능을 먼저 잰다(개선폭 입증의 기준)
  3. LLaMA Board에서 SFT(능력 학습) 실행, TensorBoard로 진행 확인
  4. 담당자 판정·재작성 이력으로 DPO(선호 학습)
  5. 학습 모델을 서빙에 연결(.env.local의 VLLM_BASE_URL)

베이스라인 측정 전 파인튜닝을 시작하지 않습니다 — 개선폭을 수치로 입증하는 것이 목표입니다.
