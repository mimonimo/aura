모델 개발 트랙 (4종) 상세

오픈웨이트 모델을 교내 국고사업 문서 도메인에 맞춰 학습시키는 4종입니다. 지식(수치)은 학습하지 않고 능력(문체·검색력)만 학습하며, 베이스 대비 개선폭을 정량 입증하는 것이 목표입니다.

모델베이스역할학습 방식상태
ZZAIMY-EmbedKURE-v1 도메인 특화 임베딩(검색)대조학습 — 합성 질의쌍 v0 실험 · 베이스 유지
ZZAIMY-Rerankbge-reranker-v2-m3 검색 재정렬동일 데이터 재활용 베이스 사용 중
ZZAIMY-WriterQwen3.5-35B-A3B (MoE) 계획서 섹션 생성QLoRA SFT 예정 · 베이스라인 후
ZZAIMY-ExtractQwen3-4B 실적 카드 추출증류(distillation) SFT 예정

※ 학습이 실제로 착수된 건 임베딩(v0)뿐이며, v0는 베이스(KURE)를 못 넘어 미적용 상태입니다. Writer·Extract 학습은 GPU 서버 확보 + 베이스라인 측정 후에 착수합니다(순서 원칙). Qwen 계열 베이스는 기관 수용성·명명 확인 대기.
