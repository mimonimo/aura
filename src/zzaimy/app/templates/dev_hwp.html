한글 실시간 편집 채널

Windows PC의 한글(HWP)을 서버 지시로 실시간 편집하는 채널입니다. PC에서 에이전트를 실행하면 바깥 방향으로만 서버에 붙고(방화벽 개방 불필요), 아래에서 보낸 명령이 열려 있는 한글 화면에 바로 반영됩니다. 자연어 지시 변환은 LLM 연결 후이며, 지금은 정해진 명령으로 경로를 검증합니다.
